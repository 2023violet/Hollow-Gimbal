## 生产 API 与机械模型

[公开接口](../../calibration/include/foc_mechanical_id.h) 提供 `foc_mechanical_id_init`、`foc_mechanical_id_push`、`foc_mechanical_id_finish`、`foc_mechanical_id_reset`，由调用方分配实例并持有采集配置。启用新会话需要不同的非零 capture ID，setup ID 约束电机/机械装配、方向、参考点和校准，torque-model ID 绑定 Kt、来源和适用范围。结果附来源、窗口数、时基、激励、条件、残差、失败类别和 `usable`。无效配置保留已存在的会话；有效采集的坏端点在提交前拒绝并使本会话失效；成功发布 J/B 需要完整合格窗口，失败时两项均为零。没有部分候选，也没有自动写入。

以同一有符号电机轴机械坐标表示 \( J\dot\omega+B\omega=\tau_e-\tau_L \)，其中 J 单位 kg·m²，B 单位 N·m·s/rad，负载 \(\tau_L\) 为带符号反向作用转矩。合同接受两类 \(\tau_e\)：

- 经独立 Kt 和 Id 范围资格确认后的**观测** dq 电流，取 \( K_t I_q \)。采集方确认 dq、电机轴方向和扭矩模型同源。
- 独立校验的全电磁等效转矩。模型外摩擦、间隙、温度变化、高 |Id| 显著磁阻项或不可忽略的未知负载，超出已验证范围。

任一有效端点须提供同一原始时基的速度和转矩时间戳、前一端点的区间起点、有效标志及帧/区间确认。第一端点无前置区间。后续要求同一会话和来源、严格向前的模 32 位序号及时间、区间在配置内。主机时钟重置或跨整个计数周期的遗漏由采集方保证排除。明确未知负载或未校验的输入立即拒收。时间戳相同仍须证明滤波有效时延与输出、电流测量的实际时序。

每个完整窗用实际间隔按梯形法累积 \(\omega\) 和净转矩，用两端速度差计算平均加速度。回归列为 \(\Delta\omega/T\) 与 \(\int\omega\,dt/T\)，观测为 \(\int(\tau_e-\tau_L)dt/T\)。六项 Double Gram 统计量支持常量空间、逐端点定长计算，最多 65,535 端点，窗口之间只共享边界。要求至少三个完整窗口、每窗至少两个区间，双方向速度变化超过分辨率门槛，以及足够的速度和加速度 RMS。以 \(1-r^2\) 和 \((1+|r|)/(1-|r|)\) 检查独立性及报告归一化条件数。J 严格正、B 非负且落在配置物理范围。用实际发布的 Float32 J/B 评估残差上界，包含 Double 累积误差预算。

配置还约束 \(B_{max}\Delta t_{max}/J_{min}\leq0.3\)。独立复核曾用精确线性 Plant、0.8 s 采样和三角激励推导出约 +107.5% 的 J 偏差，残差却约 0.000000000753 N·m。新门槛拒绝这组配置。它约束机械极点对应的积分误差，采集方仍须对快于机械极点的电流波形、滤波和采样分辨率负责。

## 模型到正式 IMPEDANCE 闭环

A 使用 01C 历史固定 K/D 0.65/0.048。B 使用真值，C 使用独立训练冻结的估计，两者走既有 `foc_impedance_tuning_design()`，共同目标 18 rad/s、ζ=0.75，实际 Kt、H1 周期、延迟预算和限流一并输入。C 标称 K/D 为 0.648569/0.048051，C 4× 为 2.594994/0.210226；对应 4× B 为 2.592/0.210。Host 调用方显式将候选作为同一事务的命令参数输入，正常 SET_MODE→ARM→START，H1 根据生产 Sensor 和命令计算，H0 继续通过 Current、Pipeline、Safety 和虚拟提交。候选不会自动配置 Runtime，也没有新在线调参。

## ARM 静态成本

Arm GNU 14.3.1，Cortex-M4，soft ABI，`-Os` 独立编译。实例 288 B；配置 76 B、样本 56 B、独立结果缓冲 112 B（均为类型大小，实例已包含内部配置和结果）。对象 text 3,600 B、data/bss 0 B。静态函数栈帧 init/reset/push/finish 分别为 152/96/112/120 B。复位可调用 init，静态帧不等于调用链总栈，库调用和抢占开销亦未测。Double 有助于累积和解算尺度差、计算残差上界；独立对象引用 `__aeabi_d*`、转换、`sqrt` 和 `fmax`，实际链接成本受现有镜像库依赖影响。本次锁定 AT32F415 参考固件无机械辨识符号，H0/H1 生产调用点无新增开销，镜像 Flash/RAM 40,060/3,880 B，BIN 与 01C 逐字节相同，SHA-256 为 `9f6da4ecf8fe281917fd00d1b1cdec8d9e818f33328093549e2fb1cc99e52527`。这些静态记录不构成实测栈高水位或 WCET。
