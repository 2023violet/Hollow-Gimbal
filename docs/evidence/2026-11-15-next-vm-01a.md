## 实现范围

新增 `simulation/` standalone Host project：

- `foc_virtual_motor`：无全局可变状态的双精度平均值 PMSM RK4 Plant；参数、状态、负载、alpha/beta 电压和显式 `dt_s` 均由调用者控制。
- Virtual ADC：从 Plant 的 d/q 电流生成三相电流、VBUS 和量化 ADC ranks，支持 ABC/ACB 相序和无效范围标记。
- Virtual Encoder：从连续机械角生成量化绝对码，随后调用现有 `foc_encoder_update()`。
- `foc_virtual_current`：调用真实 `foc_runtime_init()`、`foc_runtime_h1_step()`、`foc_runtime_h0_step()`、`foc_runtime_foreground_poll()` 和 `foc_runtime_publish_command()`。
- Virtual output adapter：接收真实 `struct foc_device_pwm_request`，使用 `foc_device_sim_submit()` 验证；只有接受 UPDATE 后才更新 Plant 的下一段零阶保持电压。
- Host-only executable：`falconfoc-virtual-current.exe`。

没有调用 `foc_board_init()`，没有修改 `firmware/at32f415/src/foc_board.c`，没有修改真实 PWM、ADC、Timer、SPI、Serial、Protocol 或 Board1 Safety 行为。

## 虚拟时间与事件顺序

默认 Profile 为 `GENERIC_RESEARCH_MOTOR`：12 V VBUS、4 极对、Rs `0.6 Ω`、Ld
`1.2 mH`、Lq `1.5 mH`、磁链 `0.025 Wb`、惯量 `0.002 kg·m²`、阻尼
`0.006 N·m·s`、Current PI `Kp={1.08,1.35}`、`Ki={540,540}`、电压上限
`2.4 V`、电流上限 `2.5 A`、H0 `200 us`、H1 `500 us`。

每个事件边界遵循：

```text
此前已接受的输出推进 Plant 到当前虚拟时间
  -> H1 生成 Encoder code、调用 foc_encoder_update、发布 Sensor
  -> Foreground supervision / heartbeat
  -> H0 生成 ADC ranks、执行 Runtime/Safety/Current PI
  -> 只有输出回调接受 UPDATE，才让该 UPDATE 成为下一段 Plant 输出
```

新 PWM 请求不会回写影响产生它的 ADC sample。Host 执行耗时不被当作 MCU WCET。

INHIBIT 的虚拟语义是高阻近似：移除平均定子电压，保留电流衰减、惯性、阻尼和
外部负载演化；这不是物理桥臂关闭，也不是主动制动模型。

Plant、传感器和 Runtime 事件序列可重复。
