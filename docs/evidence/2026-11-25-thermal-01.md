# THERMAL-01｜I²t 过载保护与 NTC 温度降额

2026-11-25，分支 `codex/falconfoc-v2-vm01a`，基线 `4f5b32a`（MIT-01）。只做软件验证，没有上板；Board1 没有 NTC 通道。

## 结论

Runtime 增加 I²t 过载模型（默认 τ = 30 s，设置额定电流 ID 96 后生效）：θ 到 1 时电流上限折返到额定电流，到 1.25 锁存 OVERLOAD。NTC 降额与过温跳闸的代码已就绪（可移植的 `g3/safe/foc_thermal` + 板级 `foc_board_thermal`），默认关闭，等硬件接入。SIL `thermal` 场景全部通过，数值与理论一致。

## 改动

- **g3/safe**：`foc_thermal`（β 换算用无 libm 的 ln、两级滤波、线性降额、跳闸回差、断线跳闸、I²t 系数与步进）；故障位 OVER_TEMPERATURE_FET 17、OVER_TEMPERATURE_MOTOR 18、OVERLOAD 19，均可由 FAULT_CLEAR 清除。
- **Runtime**：`foc_runtime_profile.thermal_tau_s`（末尾）；H0 每周期更新 θ、计算热上限（I²t 与板级降额取小）、请求 OVERLOAD；快速输入追加 `thermal_derate`、`thermal_faults`（按 nFAULT 方式只锁存一次）；清除条件加"传感器跳闸已释放、θ < 1"；`foc_pipeline_input.target_limit_a/target_limited` 钳位电流目标幅值；H1 外环 q 电流上限取热上限；`foc_runtime_read_thermal()`。I²t 开启时 SUSTAINED_CURRENT 门限改为 0.95 × ID 68。
- **Board1**：`foc_board_thermal`（前台 10 ms 轮询，读取端口 `foc_board_ntc_reader`，ARM 镜像不提供读取函数）；串口 `thermal` 设置与 `temperature` 读数；存储保存/恢复/校验，CONFIG_ERASE 恢复默认；写入交叉校验（降额起点必须低于上限）。
- **参数**：119、135–148 写进 `parameters.json`，新单位 °C 24、s 25、K 26；生成器允许串口组只读字段。
- **CAN**：Get_Temperature 返回两路温度；达妙温度字节与错误码 B/C；CANSimple INVERTER_OVER_TEMP 0x4000、MOTOR_OVER_TEMP 0x2000。
- **SIL / CLI**：SIL 一阶热模型（`--thermal`）与温度注入窗口（`--ntc-override-us`）；场景 `thermal`、SIL 测试 `test_thermal_protection`；CLI 故障名与 CAN 错误名补齐。

## 验证

- `test-foc-thermal`：β 换算与 libm 对照（两种接法，−20..140 °C 误差 < 0.02 °C）、滤波初值与重置、跳闸回差、断线 10 次跳闸、降额、I²t 时间线（2 倍额定到 θ = 1 用时与 τ ln(4/3) 差 < 1%，额定电流稳态 θ = 1，无电流 τ 后衰减到 e⁻¹）。
- `test-foc-runtime-thermal`：固定 1 A 读数对 0.5 A 额定、τ 1 s：288 ms 折返、375 ms 锁存 OVERLOAD；冷却到 θ < 1 前清除不生效，之后清除成功；SUSTAINED_CURRENT 门限 4.75 A / 0.5 A 切换；保护关闭时 I²t 关闭；τ 0.5 s / 4000 s 被拒；降额 0.5 → 上限 2.5 A，NaN → 0 A；温度故障锁存一次、未释放前清除不生效。
- 固件：存储往返（电机通道、拓扑、τ）与非法组合拒绝；串口写入交叉校验、只读温度默认 NaN、θ 0、上限 = ID 68；`foc_board_thermal` 轮询节拍、85 °C 降额 0.5、断线跳闸、无读取函数时双通道跳闸；CAN 错误位、Get_Temperature、达妙温度字节（41.5 °C → 42，300 °C → 255）。
- SIL `thermal`（[结果](2026-11-25-thermal-01/sil-thermal.json)）：默认温度 NaN、θ 0、上限 2.5 A → 额定 0.5 A、τ 2 s、请求 1 A：615 ms 观察到折返（理论 575 ms，参数读取间隔约 40 ms），θ 峰值 1.002，稳态电流 0.5000 A → 停机 2 s 后 θ = 0.3679（e⁻¹）→ 电机 NTC 降额 40..60 °C、被控对象 Rth 40 K/W、τ 1 s：环境 25.0 °C，平衡 0.881 A / 52.95 °C，上限读数 0.881 A（理论 0.881 A / 52.95 °C）→ 注入 80 °C 后 130 ms 锁存 OVER_TEMPERATURE_MOTOR → 读数回落前清除不生效 → 回落后清除成功。
- UART 线上录制：新增 ID 之外的 2,857 条参数读写回应中 2,847 条与 MIT-01 逐字节相同；其余 10 条是 ID 60/62（调参修订号与请求序号）各 +3，对应扫描中 ID 135 被接受的 3 次写入。

## 局限

- Board1 没有 NTC 通道；使能通道会因无读数跳闸。接入时在 `main.c` 提供读取函数即可。
- I²t 只用电流平方，不含铁损与环境温度；τ 需按电机给定。SIL 热模型为一阶，仅验证逻辑。
- 降额只改电流上限，不改 PI；接入真实 NTC 后需台架确认滤波与回差。
