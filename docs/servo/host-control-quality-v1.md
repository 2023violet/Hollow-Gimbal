# FalconFOC Host 控制品质验收 V1

本规范用于后续 Host 产品验收。每份报告保存源码身份、运行工具、标定审核指纹、配置、输入、原始轨迹和评价版本。实板采样、去能、PWM 生效和 WCET 单独验收。

## 共同判定

先验证轨迹完整、配置已审核、同窗对照、时间和会话正确，再判断品质。有效控制样本要求 Runtime 为 RUNNING，H0 当前观测有效且输出事务在本拍确认 UPDATE。外部目标是误差参照。停止、故障和未启动的样本另评估状态、撤销和自然衰减。出于安全而正确撤销输出可通过相应生命周期门槛。非法输出、限值超界或拒绝后提交控制状态属于控制缺陷，必须修复并用同一复现输入验证。

| 结论 | 判定依据 |
| --- | --- |
| `CONTROL_QUALITY_PASS` | 适用且可行的固定门槛与安全/事务全部满足，证据足以重现。 |
| `CONTROL_QUALITY_FAIL` | 任一适用的门槛失败，或有实现缺陷。记录失败窗口、指标、阈值与原因。 |
| `LIMITED_BY_FEASIBILITY` | 对指定目标、限值与工况独立推导驱动/转矩/时间下界，并有接近限值的实际输出和响应轨迹。安全限幅、卸载和 STOP/FAULT 仍需达标。静态可行只证明有平衡点。 |
| `CONTROL_TRADEOFF_DOCUMENTED` | 同条件 A/B 已量化收益和代价。说明受影响场景、保留或采用何种策略、继续使用的门槛。可与某个历史失败同时记录。 |
| `INSUFFICIENT_EVIDENCE` | 缺少合法执行、数值或时序见证，无法应用前述判定。 |

## Current Startup V1

Generic 与 Salient 使用同一组正反向场景，均先通过原标定审核与新 Runtime 初始化。生产基线为 130 Hz PI，名义母线 12 V，限压 2.4 V，电流目标矢量上限 2.5 A，H0/H1 为 200/500 µs。报告保留各实际生效的 ADC、编码器、模型及增益。轨迹从 t=0 开始，第一次命令发布于 700 µs，ARM 于 1,400 µs，START 于 1,800 µs。每 1 ms 刷新同一外部目标，活动区观察 60 ms 后 STOP，继续观察 1 ms。

| 场景 | 固定输入 | 门槛 |
| --- | --- | --- |
| 小/名义/大冷启动 | ±0.15 / ±0.45 / ±2.20 A | 从模型首次施压起 4 ms 内进入并保持误差带。小与名义超调 ≤0.08 A，大幅超调 ≤0.18 A。 |
| 运行中反向 | 由 ±0.45 到 ∓0.45 A，活动窗 30 ms 切换 | 切换后的同拍端口证据完整，4 ms 内进入并保持误差带，超调 ≤0.08 A。 |
| 低压反向与退出 | 6.1 V 母线，0.72 V 限压，±2.20 → ∓0.35 A，30 ms 切换 | 首阶段独立评估电压可行性，要求确有近限压、始终遵守限幅。退出后 15 ms 内进入并保持误差带，尾段不近限压，超调 ≤0.08 A。 |
| 电气参数相反失配 | 仍用原审核增益，Plant Rs/Ld/Lq 分别乘 1.25/0.80/0.75 或 0.80/1.20/1.25，±0.45 A | 8 ms 内进入并保持误差带，超调 ≤0.08 A。 |

误差 `e[k]=iq_plant[k]−iq_external[k]`（A）。误差带 `max(0.04 A, 10%·|iq_external|)`，每个目标段独立计分。首入记录第一个在带内的采样点，始终在带内的后缀从最后一次越界后的下一样本开始，要求至少 2 ms 已观察保持。调节时间是施压至该后缀开始，保持时长由最后观测减后缀开始。RMS 为有效样本 `sqrt(mean(e²))`，全窗峰值为 `max(|e|)`，尾段偏差是后 25% 样本的平均误差，超调为 `max(0, sign(iq_external)·e)`。首拍和每拍的电压幅值由已接受适配器读回，距有效电压上限 2 mV 内记录为近限压，累计每样本 200 µs。可行目标的尾段要求退出近限压。该观测有意保留阈值和原始幅值。另存积分、电压、命令和反馈时间。

**事务门槛。** 逐拍记录命令发布/消费、ADC、H0/H1、更新回执、模型施压。发布等待与首次施压后的电气响应分别计量。始终检查电压限制、会话及更新连续性，STOP 后零有效 UPDATE。故障注入及恢复沿用原独立 Runtime/Board Host 事务门槛。对新策略额外验证取消、无效参数和会话变化。冻结历史 10 ms Current 的全窗、RUNNING 子窗和兼容裁决原样留档。

## Impedance V1

保留原 Servo Holdout 的模型、编码器、窗和固有阈值，包括 q 请求和 Plant q 高频 RMS ≤35 mA、同一冻结 Servo-02D 动态与恢复断言。运行与安全评估使用同一份 H1 目标提交和 H0 回执。隔离 D 支路 A/B 只改变截止频率，保留其它配置和原输入。

转矩边界配对模型使用 1.3 倍惯量 Generic，Kt≈0.15 N·m/A，Core/Motion 0.25 A，12 V 母线、2.4 V 限压、B=0.006 N·m·s/rad。正反向目标、0.8–1.5 s 脉冲、±0.030、±0.03675、±0.039 N·m 和卸载按对应归档固定。原可行用例继续按 250 ms 最长限幅及原其它质量门槛。峰滑移、负载尾窗净转矩、持续限幅、卸载至误差带、积分、STOP/FAULT 以逐周期记录验证。不可行场景另外要求转矩/电流请求受约束、无失控积分、卸载后恢复且无非法 UPDATE。保持与滑移分别评定，粘性阻尼在非零速度的辅助贡献不能计作静态可用转矩。近转矩点可同时保留静态可行与动态 FAIL。

## 历史结果与复跑

新的标签记录在本版报告，原测试名称、参数、失败位和裁决保留。历史 Current 首点即在误差带的缺口按控制取舍记录，证据表明原 2.4 V 的 Host 模型存在物理解。历史 `hold-load-beyond-025` 的 bit 16 保留，其持续静止目标另归 `LIMITED_BY_FEASIBILITY`。此前修复的低调制比舍入误停按缺陷回归。 [CQ-01](../evidence/2026-11-20-next-cq-01.md) · [CQ-02](../evidence/2026-11-20-next-cq-02.md)
