## 生产接口与运行规则

- [Motion Limits C11 API](../../core/include/foc_motion_limits.h) 校验有限且严格递增的连续机械位置区间、非重叠容差带和非零机械坐标身份。绝对目标必须落在闭区间内。边界处或已在界外时，仅接受合法回转或不向外的请求。
- [Following Error C11 API](../../core/include/foc_following_error.h) 以 `|最终有效位置参考 − 实测连续机械位置| > 阈值` 为条件，使用原始采样时间。重复样本零增量，向后或存在半程歧义的时间被拒绝，采样过久重新计时。越阈为 `PENDING`，连续达到持续时间为 `TRIGGERED`，阈内、无参考、无效反馈及顺序错误有独立语义。允许正常 UInt32 回绕。
- [运动保护配置与模式矩阵](../control-plane/motion-protection.md) 记录各模式、回转、坐标和时间规则。POSITION 检验绝对目标、速度和最终 q 电流。VELOCITY 检验原始速度、整形速度与速度 PI 合成后的 q 电流。IMPEDANCE 检验绝对参考、速度和弹簧、阻尼及前馈合成限幅后的 q 电流。CURRENT 在位置软限位启用时返回等效不支持。无位置参考的模式不累积跟随误差。
- Foreground 拒绝越界绝对目标。H1 根据机械反馈和命令生成提案。H0 核对实际消费的提案、反馈年龄、因果顺序、坐标身份、模式和 Session，经原 Pipeline 输出门禁后才能提交。当前允许比较实际请求的方向，实际速度或机械位置由物理系统决定。
- [Control Plane 参数表](../../control_plane/README.md) 增加九个配置 `0x100B–0x1013` 和两个只读诊断 `0x3010–0x3011`，共 41 项参数及诊断、5 个动作。静态设置批量形成独立候选，仍受 Session、DISABLED、无故障及确认 INHIBIT 准入约束。调用方在初始化时应用。旧参数 ID、动作、UART V1 和 Board1 默认参数继续使用既有语义。

## STOP、Safety 和输出事务

[直接 Runtime 回归](../../runtime/tests/test_foc_runtime_protection.c) 以 H0 100 µs、H1 200 µs 构造同一超差门槛拍。重复消费采样不增加持续时间。每个工况在门槛前确认四次 UPDATE，门槛拍与其后的拒绝均保留 Current PI 积分。

| 门槛拍事件 | Runtime / Pipeline | 软件确认、会话和故障 |
| --- | --- | --- |
| 正常持续超差 | `ERR_STOP / ERR_STOP` | 确认 INHIBIT，Session 1→2。单独报告 `TRIGGERED / FOLLOWING`，故障位 0。 |
| ADC 无效 | `ERR_CONTROL / ERR_SAMPLE` | 确认 INHIBIT，Session 1→2。保留 `SAMPLE_INVALID` 锁存，未记作跟随超差。 |
| 机械反馈超龄 | `ERR_ALIGNMENT / ERR_SAMPLE` | 确认 INHIBIT，Session 1→2。保留采样故障和无效反馈诊断。 |
| 提交点独立 STOP | `ERR_STOP / ERR_STOP` | 确认 INHIBIT，Session 1→2。保留 WDT 锁存，未记作跟随超差。 |
| 适配器拒绝 INHIBIT | `ERR_STOP / ERR_INHIBIT` | 快照仍为输出未确认，Session 1→2，保留跟随诊断。四次已确认 UPDATE 原值不变。 |

持续超差走既有 Pipeline 提交 Guard，以及原有 STOP、INHIBIT 和 rearm 路径。旧 Session 或旧序号的命令不能重启控制。停止恢复需要新传感样本和命令、显式 ARM/START。跟随诊断与 Safety 错误位独立。

独立代码复核发现一个 P1。初版在普通 Pipeline 执行前处理跟随超差，可能跳过同拍 ADC/Safety 锁存。修正后原 ADC 和 Safety 先执行，独立 STOP 在 Guard 中具备优先权。复核者再次检查最终路径，未发现剩余 P0/P1。同拍测试由主代理执行。复核与测试证据均在原始归档。

## 边界与下一阶段

本轮证据支持软件指令约束、持续跟随误差检测和 Runtime 停止事务。Host 高速反例展示了实际位置仍可越界。外载、制动能力、功率级、齿隙与采样延迟都需要单独验证。当前状态为 `G3-SAFE HARDWARE NOT VERIFIED`、`G3-PWR LOCKED`、`AT32F415 WCET NOT VERIFIED`、`MOTOR PHYSICAL OPERATION UNVERIFIED`。

相比 robot_mc，仍缺少按设备保存的限位/保护配置、输出轴减速比定义的统一集成、纯力矩模式的方向门控、丰富的运行期输入形态及 Servo 转矩配合速度限值。恢复策略也更严：robot_mc 文档允许界外时将目标设在当前位置和边界之间，FalconFOC 要求回转的绝对目标位于区间内。FalconFOC 跟随阈值与持续时间显式配置，可对能力不足的持续超差停止。robot_mc 文档描述的饱和判据和定时策略不同。 [robot_mc 固定版本参数说明](https://raw.githubusercontent.com/cyberbeast0829/robot_mc/2f1fb61ec081eb7a42ab8436ba8f1504fc529da7/docs/parameters.md)

可以进入 SOFT-03 配置持久化设计与软件验证。建议把区间、机械坐标身份、跟随阈值和时序作为一组进行版本迁移、断电恢复、原子提交及错误回退测试，继续复用既有静态候选准入。对实机安装、Board 功率输出及对外 SDK 发布分别验收。
