### 参考和力矩是否可达

冻结反向实际是 **三次位移过渡**。在 1.12–1.45 s 内从已停住的正向轨迹末端移动 −0.28 rad，\(p=p_0-0.28(3s^2-2s^3)\)，\(s=(t-1.12)/0.33\)。位置和速度连续，速度两端均为零，并无正负速度瞬时跳变。反向入口的参考加速度从 0 跳到 −15.427 rad/s²，接近反向末端为 +15.427 rad/s²，随后重新归零。所需转矩有限，J/B 理想峰值 **40.11 mN·m**，约占可用 **315 mN·m** 的 12.7%。三臂在 660 个反向样本均无饱和。入口需要有限但突变的转矩，实际电流具有上升时间，出现非零短时误差符合模型。当前物理上限不构成 0.25 rad/s 门槛的主要约束。额外的同参考 Host 诊断保持原立项种子、采样、约束和三次位置指令。无前馈复现 **0.30985 rad/s**，6,000 拍的原码、指令、采集/H0 时间及 q 请求与 02B A 相同。另一臂以分段导数生成同参考的理想 J/B 前馈，反向 RMS 为 **0.00947 rad/s**、零限幅。这直接证明原命令在该 Host 条件下可达 0.25 门槛。诊断仅用作归因，历史 02B FAIL 及同场景静止噪声仍保留，分段导数未作为新 API 的连续加速度研究样本。

反向首 25 ms 的参考平均转矩为 **−38.21 mN·m**，A 平均实际 KtIq 为 **−7.11 mN·m**。反向制动段需要平均 **+14.89 mN·m**，A 实际为 **+6.59 mN·m**。A 约 **63.4%** 的冻结平方误差集中在反向制动而非命令入口。B 的 D 降低后制动误差更大。C 保持 D、平滑反馈后，制动实效平均 **+7.32 mN·m**，命令到观测电流对应的转矩残差 RMS 从 A 的 **8.87 mN·m** 降到 C 的 **1.41 mN·m**。该残差含电流动态、扰动与两种观测的时序，数值不能分配为 Current PI 独立责任。C 的制动误差仍占约 **62.8%**，整个窗口仍超门槛。

对 A/B 另解零 Sensor、调度与转矩跟踪延迟的线性反馈误差方程 \(J\ddot e+(B+D)\dot e+Ke=J\ddot p_{ref}+B\dot p_{ref}\)，初值取每条已记录的反向入口状态。理想反馈仍得到 0.313/0.379 rad/s，说明有限反馈增益承担整段惯性和粘性需求，已经足以解释原超限的大部分。H1 发布至 H0 ADC/提交为 **0 或 100 μs**，真实捕获到 H0 的年龄 **1–137 μs**。H0 用原机械速度和电角预测，虚拟占空比在 H0 接受后进入下一段积分。离线把原参考平移 33.5–42.5 ms 可降低描述性对齐误差，该量表示响应轨迹的等效滞后，与测得的软件调度耗时分别列出。实际加速度从连续 H0 Plant 状态有限差分求区间平均，\(J\Delta\omega/\Delta t+B\bar\omega\) 用于核对电磁转矩；和 \(K_t\overline{I_q}\) 的 RMS 差为 0.025–0.151 mN·m。这一 Kt 代理未展开磁阻小项，原始字段与计算相互区分。

## 生产 C11 接口和适用范围

早期在相同连续参考和时序下验证了模型前馈价值，才新增 [`foc_impedance_feedforward_evaluate()`](../../core/include/foc_impedance_feedforward.h)。输入为 J>0、B≥0、轨迹同一时刻的参考速度及加速度、非零已资格模型身份、一致的电机轴参考与模型帧身份、资格标志及独立前馈转矩限额。函数无状态，使用 Double 乘加及边界余量判断，返回 Float32 转矩与模型/坐标身份。准入失败清空结果。转矩超过预算时明确拒绝，保留调用方决定如何处置。接口不读取时钟、Plant 或控制器状态。

前馈项是 \(J a_{ref}+B v_{ref}\)。弹簧和阻尼继续基于位置与速度误差，粘性项只补模型运动所需的轴上阻力。已知外载可在调用方另列为经资格确认的独立项。本轮动态扰动用于检验跟踪和恢复，未注入 Plant 真值负载补偿。调用方把模型候选显式放进现有 `foc_runtime_publish_impedance_command()`，合成转矩仍接受 H1/Core、H0、Current 和 Safety 限幅。02A 的模型来自独立采集，经先前辨识/预测质量准入，再从原归档数值冻结。D 使用 02A 标称 capture 100，\(J=0.002001755405\) kg·m²、\(B=0.00599673437\) N·m·s/rad。C 读取实验配置的真实参数仅作为 Host Oracle；独立计算 API 只消费传入的模型和参考。
