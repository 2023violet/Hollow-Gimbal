# NEXT-ENCODER-LINEAR-01B｜从独立参考观测生成并验收编码器 LUT

2026-11-27。**PASS，C11 自主生成和受控 Host 验收通过。** FalconFOC 可以用原始码值与独立参考机械角拟合周期补偿表，并用另一采集会话验收冻结后的整码表。三张进入真实软件控制链的 64 节点自动表在独立 Holdout 的机械角 RMS 为 **0.049–0.180 mrad**。Sensor 与 H0 的实现维持 01A，锁定固件 BIN 逐字节相同。

## 1. 生产 API 与参考角契约

| 状态 | API 和条件 |
| --- | --- |
| TRAINING | `foc_encoder_cal_init()` 固定 Sensor 配置、编码器和参考身份、来源、节点数、零位和阈值。`push()` 接受同一会话的有效配对。 |
| FROZEN | `foc_encoder_cal_freeze()` 检查覆盖、几何条件、零位、量化、Sensor 准入和分段残差后冻结节点。 |
| HOLDOUT | `foc_encoder_cal_begin_holdout()` 采用不同采集 ID。首对的时间戳必须在同一时基上晚于 Training 最后一对。只用冻结表评估。 |
| VALID | `foc_encoder_cal_finish()` 检查全段覆盖、准确 RMS 和峰值，并要求相对原始码 RMS 不恶化。`export()` 可复制自有表，`make_lut()` 提供供 Sensor 初始化使用的只读描述符。 |
| INVALID | 保留已接受计数和诊断，清除未交付节点。`reset()` 保留配置并开始新采集。无效操作保持其他实例和已导出的结果有效。 |

每一对包含原始码、独立参考机械角、CPR、方向、正式来源、编码器安装身份、参考身份、采集 ID、连续序号和两个采样时刻。两时刻必须对应同一采样孔径，程序检查同一微秒时基、相等时间戳和 uint32 模回绕顺序。采集端负责校准时基和孔径、证实参考传感器独立并据实设置资格标记。不同身份和时间检查可阻止明显的串接或重放，真实参考的独立性、机械联接及延迟仍由外部证据支持。Host 使用 Virtual Motor 的真实机械角作为独立参考。

采用**已知参考零位**。先从参考机械角减去外部确定的参考零位，再按 Sensor 方向转换为无方向的原码坐标。拟合的量是环形最短差 `reference_in_raw_frame − raw_code`，自变量是观测到的原码，由配对样本直接拟合逆映射。拟合后报告有符号节点均值，超零位阈值则拒绝，通过后从各节点减去均值再量化。未量化节点均值为零，整码量化后的平均余量不超过半个计数。机械零位与既有电角 Offset 仍由原有标定定值，本模块不修改它们。 [公开接口](../../calibration/include/foc_encoder_calibration.h) · [集成说明](../../calibration/README.md#offline-encoder-lut-generation)

## 2. 有界拟合与质量门槛

4–64 个等距节点，每段至少覆盖四个原始码。生产算法每段只保留线性回归的五个 Double 累积量。每段用自身采样拟合左右端点，相邻两段的端点估计在共同节点取平均，周期末段和首段同样处理。Training 和 Holdout 各要求每段样本数够用、四个子区间齐全。Training 还要求归一化位置方差至少 0.01，避免少量边缘点掩盖密集聚类。任何缺段都使整表不可使用。

单次采集最多 65,535 对。接受前检查来源、CPR、方向、两时间戳、序号、有效性、有限角和源姿态资格。观察到的校正幅度超过 CPR/8 时拒绝。节点取最近整码，正中向 +∞，检查 `int16_t` 可表示性；实际整数表交给 01A 准入，沿用 CPR、身份、最大幅值、首尾及局部斜率合同。Training RMS 根据量化后的节点和连续插值计算，并计入与数值规模相关的误差项。分段峰值 RMS 用于捕获局部异常。Holdout 则逐样本调用现有 Sensor `foc_encoder_correct_code()`，包含实际整码舍入，直接得到最大角误差和 RMS。节点在两阶段之间逐字节保持。 [拟合与冻结](../../calibration/src/foc_encoder_calibration.c#L339) · [验收与导出](../../calibration/src/foc_encoder_calibration.c#L423)

本轮回归保留四组失败质量证据。

| 异常数据 | 结果 |
| --- | --- |
| 只覆盖 31% 圈，输入 6,143 对 | 缺段拒绝 `UNIDENTIFIABLE`。总样本数无法代替分段覆盖。 |
| 注入一次 25 mrad 离群参考 | 全部 6,143 对送入评估，最差段 RMS **3.264 mrad**，超过 **0.322 mrad** 阈值。 |
| 一对参考时间戳偏后 1 µs | 在 61 对接受后以 `TIME_ORDER` 拒绝，拒绝帧不入累积。 |
| 声明的参考零位错误 20 mrad | 拟合零位偏差 **−20.000 mrad**，以 `CONFIG_MISMATCH` 拒绝。 |

正式单测还覆盖独立实例、重置/导出原子性、序号和时间回绕、缺段 Holdout、超峰值 Holdout、非法参考、方向和来源错配，以及与 01A 斜率边界冲突。

## 3. Training、独立 Holdout 与表数据

原码由现有 Virtual Encoder 和量化器产生。生产标定器只见成对观测。Training **6,143 对**，Holdout **4,093 对**。二者完整扫一圈但使用不同起始相位、方向、角度密度和采样点。Training 角位置密度调制幅度 0.63 rad，Holdout −0.29 rad。参考噪声为有界确定性 LCG，种子分别为 `0x49f65a7b`、`0x931e2a13`，幅度 ±0.20、±0.16 原始计数。夹具已知参考零为 0.21 rad。开始 Holdout 前冻结整数节点和质量阈值。

设 CPR 对应整码角度 `q=2π/CPR`，段宽 `w=2π/N`。受控实验预设曲率预算 `K=0.18`。Training 段 RMS 门槛为 `1.1q + K*w²/8`，Holdout RMS 为 `1.25q + K*w²/8`，峰值为 `2.5q + K*w²/4`，零位界为 `0.001 + 2q`，并要求每段至少 16 个样本、四个子区间齐全。曲率项覆盖研究波形插值误差，码值项容纳原码、参考噪声和 Sensor 舍入。各阈值是本轮受控 Host 政策。

## 4. 真实 Sensor → H1 → H0 → Pipeline → Current

A 为理想原码，B 为同畸变且关闭补偿，C 为同畸变且显式安装通过 Holdout 的自动表，D 为 01A 的独立人工表参照。C 通过 `foc_encoder_init_with_lut()`，由实际校正后的整数相位发布 H1，H0 用既有预测，Current 实际消费预测角做 Park 变换。真值由预定相同 Plant 机械状态和相同静止坐标系电流产生。测试记录为受控数据链的测角和电流坐标误差。

## 5. 低速速度纹波及量化归因

补偿前后的两个生产 Sensor 在每个工况重放相同的虚拟原码。另用未量化的理想虚拟原码加连续 LUT 重建一条诊断轨迹，分解同一拍差分中剩余周期拟合、输入码量化和输出整码舍入的贡献。三项 RMS 相关，不能按 RMS 相加。重复码表示相邻接受反馈无增量，步进 ≥2 包括正常运动速率造成的跨码，属于量化诊断。

| 速度 rad/s | CPR / 节点 / 间隔 | Raw B → C，rad/s RMS | LPF B → C，rad/s RMS | 重复 B → C | 跨 ≥2 码 B → C |
| ---: | --- | ---: | ---: | ---: | ---: |
| +0.9 | 16,384 / 64 / 500 µs | 0.29342 → 0.31826 | 0.05649 → 0.06001 | 0 → 177 / 15,318 | 2,727 → 2,789 |
| +0.9 | 16,384 / 64 / 1,000 µs | 0.18366 → 0.20209 | 0.05180 → 0.05407 | 0 → 0 / 7,659 | 7,659 → 7,537 |
| +0.9 | 16,384 / 16 / 500 µs | 0.29342 → 0.31765 | 0.05649 → 0.06050 | 0 → 172 / 15,318 | 2,727 → 2,788 |
| +0.9 | 65,536 / 64 / 500 µs | 0.08689 → 0.10301 | 0.03144 → 0.01653 | 0 → 0 / 15,318 | 15,318 → 15,318 |
| −0.3 | 16,384 / 64 / 1,000 µs，反向 | 0.15755 → 0.16630 | 0.04383 → 0.04829 | 4,949 → 5,216 / 23,018 | 0 → 204 |

16,384 CPR、64 节点、500 µs 的三个差分误差分量为 **0.00230、0.28970、0.13213 rad/s RMS**，分别对应拟合余差、输入量化、输出舍入。相较 16 节点，64 节点显著改善角误差，速度纹波差异很小。提升 CPR 或增加采样间隔对这个模型的速度误差更有影响。爬行的正式控制链复现了 01A 的低速取舍。现有证据指向量化与有限差分的联合效应，支持后续对比速度估计方案，尚不足以直接决定引入 PLL。 [低速归因夹具](../../simulation/tests/test_foc_periodic_chain.c#L1532)

## 6. ARM 资源、回归与独立复核

Arm GNU 14.3.1 Cortex-M4 Thumb Soft-float，`-Os -fstack-usage`。新增离线对象 text **3,404 B**，data/bss 0。实例 **3,416 B**，其中 64 段累积量占 2,560 B。配置 **96 B**，导出结果 **640 B**，观测结构 **56 B**，64 节点只读表 **128 B**。静态自身栈为 init **152 B**、push **88 B**、freeze **680 B**、finish **24 B**、export **8 B**。冷路径增加 Double Soft-float 辅助调用以及标准库 `floor` 和 `sqrt`。训练、Holdout 每对 O(1)，冻结 O(N)，无运行时分配。生产 Sensor 与 H0 新增 **0 B**，采集工具可以离线部署。锁定镜像 **38,520 B Flash / 3,784 B RAM**，BIN SHA-256 与 01A 一致，`736a0eada7e43439e9d981f2649e144785eccdc50b7c01fa61f3fc7e5ee3d5b4`。

- Calibration Clang/GNU 各 **5/5**，涵盖三项标定用例与共享的两项 Sensors 回归。Sensors 独立 **2/2**，Core **15/15**，Runtime **11/11**，Simulation **21/21**。Calibration、Sensors、Simulation ASan/UBSan 分别 **5/5、2/2、21/21**。
- C/H 格式、Source Contract（89 C/H、9 CMake、9 README）、严格 Scope all（30 项 CMake 格式与 Legacy Host **45/45**）、三份 Legacy 预设、`run.sh build` 和锁定 V2 ARM 构建均通过。
- 01A 报告归档中的 10 条 Host A/B/C/D 结果和 **2,587 条**默认关闭数据一致。Motor-ID 的 **677 行**轨迹及 35 条观测质量记录一致。
- 独立复核发现两个 P2。共享 Sensors 的已注册用例未进入默认构建，经解决后独立 GNU 短枚举 Debug 校准 **5/5** 和 periodic-chain **1/1**。新测试复现了训练矩估计缺少数值余量，补上保守数值余量后通过。最终无 P0/P1 或剩余可执行问题。复核所指 16/64 采集重复已明确保留为同数据对照。
