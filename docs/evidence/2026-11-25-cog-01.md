# COG-01｜齿槽补偿（CAL-8）

2026-11-25，分支 `codex/falconfoc-v2-vm01a`，基线 `484b918`（THERMAL-01）。只做软件验证，没有上板。

## 结论

MCU 上的齿槽采集（CAL-8，掩码 16）、每圈 1024 点的 int8 表、H1 q 电流前馈和单独一页 flash 存储已接入 Board1。主机专用的 32 点实现由同一套产品机制取代（主机审查记录在初始化时重采样）。SIL `cogging` 场景全部通过：齿槽阶次的速度波动下降 92%。

同时修正 THERMAL-01 的遗漏：Board1 默认配置没有写 I²t 时间常数，实际默认是关闭的；现在默认 τ = 30 s（写入额定电流 ID 96 后生效），板级测试和 SIL thermal 场景都加了检查。

| 镜像 | 改前（THERMAL-01） | 改后 | 变化 |
| --- | ---: | ---: | ---: |
| 默认 | 102,976 B | 106,976 B | +4,000 B |
| 带参数存储 | 107,048 B | 111,968 B | +4,920 B |
| RAM（带存储） | 15,724 B | 21,972 B | +6,248 B |

程序上限因齿槽页降到 0x0801E800（122 KB），带存储镜像余量约 12.7 KB。RAM 增量几乎全是 `foc_board_cogging_state`：表 1 KB 常驻，分桶 5 KB 只在标定时用；方案估计 +1.1 KB，实际多了分桶缓冲。ROM 增量：采集与拟合约 1.5 KB，校准管理器 CAL-8 状态约 0.8 KB，H1 插值 0.5 KB，存储页与参数表约 0.5 KB，其余为串口与恢复。报告：[默认](2026-11-25-cog-01/fwsight-default.txt)、[带参数存储](2026-11-25-cog-01/fwsight-persist.txt)（两条 `foc_inverse_park_cached` "Added" 仍是同名静态函数的配对歧义）。

## 改动

- **Runtime**：`foc_runtime_cogging_table`（1024 × int8 + 每码安培数）、`motion.cogging_table/cogging_frame_id`、调参 `cogging_enabled`（均为末尾字段）；H1 在速度、位置、阻抗模式按角度取模一圈线性插值并叠加，受 q 上限、热上限和阻抗前馈余量约束；表为空时拒绝开启。主机 `FOC_RUNTIME_HOST_COGGING` 的 32 点记录在初始化时重采样进实例自己的表。
- **Board1**：`foc_board_cogging`（扫转参考按"速度 × 时间"、就近分桶的正反向滑动平均、拟合与质量判据）；校准管理器状态 18–22、失败码 18、结果位 32；存储 slot 2 齿槽页（"FBC1"，极对数与编码器身份，CRC32），PARAM_SAVE 写页、CONFIG_ERASE 擦页、恢复时无表则补偿关闭且不拒绝其余设定；`store-reserve.ld` 上限 0x0801E800。
- **协议/参数**：COGGING_READ 0x55；参数 149–156；CALIBRATE_START 允许 16。
- **CLI/SIL**：`request calibrate --cal-stages cogging`、`cogging-read`、SIL `--cogging-nm`、场景 `cogging`、SIL 测试 `test_cogging_compensation`。

## 验证

- `test-foc-board-cogging`：合成转子（84 周期 0.2 A 齿槽、0.05 A 摩擦、0.3 A 负载、0.1 A 不平衡、5 mA 噪声）表误差 < 12 mA，摩擦误差 < 3 mA，一致性 > 0.99；保留 1 次分量时表含不平衡；纯噪声 INCONSISTENT 且旧表保留、1.5 A RANGE、转子不动 SAMPLES、2 mA 齿槽 NEGLIGIBLE 并清表；参考轨迹几何。第一次试跑发现按区间取桶会把表平移半个桶（84 周期时约 0.26 rad 相位），改为就近取桶。
- `test-foc-runtime-impedance`：调参开关（2 被拒、空表被拒）、读回、阻抗提案叠加值与插值相符。主机 simulation 51 项、control_plane 5 项在新机制下全过，主机代码未改。
- 固件：齿槽页往返、身份不符（极对数、方向）、CRC 损坏、读失败、空表擦页；记录要求补偿但无页时恢复为关闭且状态 LOADED，有页时表和开关一起恢复；COGGING_READ 分块（64/24 个）与越界、长度错误；Board1 默认 τ = 30 s。
- SIL `cogging`（[结果](2026-11-25-cog-01/sil-cogging.json)）：被控对象 24 周期、0.008 N·m（0.076 A）→ 无表时开补偿被拒 → CAL-8 DONE / VALID，24 次谐波 0.0816 A（+7%），其余成分 1.5 mA，一致性 0.9988，摩擦 0.0285 A（理论 0.0286）→ 0.5 rad/s 速度模式下齿槽阶次波动 0.0283 → 0.0023 rad/s（−92%），总 RMS 0.0232 → 0.0123，后者等于无齿槽时的噪声底 0.0122 → PARAM_SAVE、断电重启后开关与表（比例逐位相同）恢复。
- UART 线上录制：新 ID 之外 3,234 条中 3,219 条与 THERMAL-01 相同；15 条差异为 ID 135 开机值 0 → 30（τ 默认值修复）、ID 60/62 各 +2（扫描中 ID 149 被接受的写入）、ID 136 的 1e-14 量级 θ（I²t 默认开启后的积分）。
- 固件 Host 19 项（含 SIL 28 项）、runtime 14 项、clang 矩阵 11 个工程、质量门禁通过。SIL 套件第一次有 2 项失败：persist 场景按旧的两槽布局计算损坏偏移（SIL flash 多了齿槽页），profile 场景期望额定电流触发定时跳闸——τ 默认值修好后 I²t 接管了这条规则（契约 27 的设计），场景改为先验证 I²t 接管、再在 τ = 0 时验证定时跳闸。fwinteg `run1` VERDICT PASS，0 findings，三套工具链各 132 项全过；SDK 技术门禁 PASS。

## 局限

- 采集要求位置环跟得上齿槽频率；SIL 用 24 周期、0.5 rad/s 和较硬的速度增益（1.5 / 30 / 8）。12 槽 14 极（84 周期/圈）在默认 0.25 rad/s 时约 3.3 Hz，默认增益下的幅值与相位需台架确认。
- 带负载标定会把负载随位置变化的力矩一起记入；编码器非线性也会混进表里（下一步编码器 LUT）。
- 需要约 2.3 圈自由转动；行程受限的关节无法标定。
- 分桶 5 KB RAM 只在标定时使用，可与标定环形缓冲共用（未做）。
