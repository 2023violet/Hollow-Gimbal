## 交付范围

- [公开 C11 API](../../control_plane/include/foc_config_diagnostics.h) 和 `falconfoc-config-diagnostics` target。单槽和双槽报告分开表达外层、TLV、语义、身份、迁移和适用性。双槽报告直接使用 [Config Store 正式选择器](../../control_plane/src/foc_config_store.c)，保留提交、CRC、序号、回绕及拒绝顺序。读两槽时只调用读回调。
- [字段比较与一致 Runtime 快照](../../control_plane/src/foc_config_diagnostics.c)。比较现有描述表定义的 19 项静态值，包括 9 项保护。结果携带稳定 ID、名称、单位、类型、左右值、可用性、重新初始化与保护标记。Float32 使用精确位比较。`MATCHES_EFFECTIVE` 是已观测静态值相符，来源仍由应用初始化路径证明。
- [Host 离线 CLI 与 JSON v1 契约](../../tools/falconfoc-config-inspector/README.md)，提供 `inspect`、`diff` 和 `explain`。只打开固定的 512 B 普通镜像。显式 `host-fixture-v1` 可检查真实 SOFT-03 Host 测试记录的适用性。其他可信配置通过 C11 API 提供。无 profile 时检查完整性、TLV 和正式 envelope 选择，身份及适用性保持未知。离线结果的 `runtime_applied` 是 `null`。未读字段依契约显示为 `null`。教程与原因表见 [诊断契约](../control-plane/config-diagnostics.md)。

当记录 CRC 有效但不兼容时，报告同时给出正式选中的 envelope 和恢复拒绝。格式未来版本只展示跨格式外层；不会把当前布局解释成其 Schema、Sequence 或身份。已知 Format 下可单独报告身份和 Schema。遇到身份或 Schema 优先拒绝时，仍可查看独立的 `tlv_reason`。CRC 用于检错，不能证明配置真实性。
