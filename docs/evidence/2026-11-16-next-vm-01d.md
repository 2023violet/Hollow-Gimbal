# FalconFOC V2｜NEXT-VM-01d Host Virtual Product Acceptance

## 结论

`NEXT-VM-01d PASS — HOST VIRTUAL PRODUCT`（Host 虚拟产品范围）。

五个演示现在都能由同一个 Host Virtual device 和 Python CLI 独立运行，
并输出真实 CSV/JSON、Replay hash、生命周期结果和虚拟/物理语义标志。
Current、Velocity、Position、Load 和 Sensor Fault 的 Runtime/Plant 链均能
执行；其中 Position 跨越了单圈连续机械角，Fault 场景经过真实 Encoder
传输失败 → H1/H0 → Safety 路径并停止新的 UPDATE。

控制品质结果没有被统一包装成 PASS：Current 记录为
`CONTROL_QUALITY_FAIL`，Velocity/Position/Load 记录为既有研究 Profile 下的
`EXPECTED_DEGRADED`，Fault 记录为 `NOT_MEASURED`。因此本轮不能称为完整的
控制品质达标验收；Host 产品集成、故障链、可观察性和独立使用交付均已通过。

独立门禁结论：`SCOPE_ALL_ENVIRONMENT_BLOCKED`。全 Scope 在 Firmware CLI
contract 因当前环境没有 Bash 阻断。

保持：`NEXT-SW-AUDIT-01 PENDING`、`G3-SAFE HARDWARE NOT VERIFIED`、
`G3-PWR LOCKED`、`AT32F415 WCET NOT VERIFIED`、`MOTOR PHYSICAL OPERATION
UNVERIFIED`。

## 4. Load Disturbance 时间线

Load Demo 使用机械负载接口 `foc_virtual_motor_set_load()`，没有直接修改速度
或位置：

```text
5000 us   load_torque_nm = +0.03
15000 us  load_torque_nm = 0.0
```

Plant 的实际负载字段随时间变化，速度和电流由正常 Runtime/Plant 链计算。
本轮固定窗口中 `speed_before_load=0.0467 rad/s`、`speed_min_after_load=0.0467`
，所以测得的速度下降为 `0`；这被保留为实际结果，没有伪造恢复时间。

## 5. Sensor Fault & Safety 时间线

Fault Demo 通过 `foc_virtual_current_fail_next_sensor()` 注入一次 Encoder
transport frame failure：

```text
5000 us   Virtual Encoder transport failure
5000 us   H1 publishes invalid sensor sample
5000 us   Runtime detects the failed feedback path
5000 us   Software INHIBIT / FAULT_LATCHED
after     accepted UPDATE count remains unchanged after the inhibit boundary
```

结果：`fault_response_us=0`（在相同虚拟事件边界识别），
`updates_before_fault=9`、`updates_at_inhibit=11`、`updates_after_inhibit=0`，
`no_update_after_inhibit=true`，最终 state `4`
（`FAULT_LATCHED`），fault bits `4`。Plant 在软件抑制后可以继续按惯量/阻尼
演化，但没有新的正常驱动 UPDATE。

这里的 `Software INHIBIT` 来自 Runtime/Output Adapter；它不等同于真实桥臂
关断、MOE 关闭或功率级安全响应。

## 10. 当前缺口和后续建议

1. `NEXT-SW-AUDIT-01` 仍需独立完成，特别是新 mailbox/Serial Policy 的并发
   交错与 32 位回绕反例。
2. 研究 Profile 下 Velocity/Position/Load 的 `EXPECTED_DEGRADED` 仍不能替代
   Board1 参数辨识和控制品质验收。
3. Fault 的软件响应已在虚拟事件边界证明，但真实故障到桥臂关断延迟、MOE、
   WDT、栈高水位和 MCU WCET 仍未验证。
4. 本轮停止在 Host Virtual Product，不自动进入 VM-01e 或硬件阶段。
