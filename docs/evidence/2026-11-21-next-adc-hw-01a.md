### 3.2 外部来源与 Attestation（`replay.py attestation_status`）

| 项 | 实际行为 |
| --- | --- |
| Host 来源 | 不接受 Attestation（`ATTESTATION_INVALID`）；结果 `PROVENANCE_DECLARED` |
| 外部来源无 Attestation | `PROVENANCE_UNVERIFIED` |
| 位置 | Attestation 必须位于 pack 目录之外，否则 `ATTESTATION_INVALID` |
| 字段 | 恰好 `manifest_sha256`、`source`、`identity`、`attested_by`；缺字段 `ATTESTATION_INVALID` |
| 绑定 | `manifest_sha256` 等于 manifest.json 的 SHA-256、`source` 与 manifest 一致、`identity` 与 manifest 一致；否则 `ATTESTATION_MISMATCH` |
| `attested_by` | 只要求为非空可打印标签，即调用方声明；不校验签名、身份或密钥 |
| 成功结果 | `PROVENANCE_VERIFIED`，说明文字为"由调用方信任的 Attestation 绑定" |

**Attestation 可以把一份外部材料与这份 manifest 摘要、来源类别和配置身份关联起来，但不会自动证明签署者真实、仪器真实、零电流真实或物理板卡身份真实。** 状态名 `PROVENANCE_VERIFIED` 只表示"摘要/来源/身份已与调用方信任的声明一致"；离线实测中以 `attested_by: "test caller label only"` 也得到该状态。本轮不改变该语义，按此范围报告。

### 3.3 ADC Candidate 准入（`board_adc_candidate.py`、`foc_board_adc_candidate.c`）

| 项 | 实际行为 |
| --- | --- |
| Board Recorded（即使附 `EXTERNAL_INSTRUMENT` 见证） | 导入器只给 `TRACE_PREPARED_PROVENANCE_UNVERIFIED`；编排器直接返回 `PRECONDITION_UNVERIFIED`（退出 3），不调用适配器，不产生候选 |
| Attestation | 编排器没有 Attestation 输入，`replay.py` 的 `PROVENANCE_VERIFIED` 不会打开候选路径 |
| 无零电流见证 | `PRECONDITION_REQUIRED`（退出 3），无候选 |
| `zero_current_confirmed` | 由调用方前提给出：编排器仅在 `QUALIFIED_MEASUREMENT_TRACE` 时传 `QUALIFIED`；适配器拒绝 `BOARD_RECORDED + QUALIFIED`（退出 2）；ADC 数据本身不携带该事实 |
| 来源标签 | Host Synthetic / Host Virtual（调用方声明）→ 候选标签；Board Recorded → 无候选 |
| 应用范围 | 候选只进入隔离实例；正式实例 ADC/Rotor/Encoder/输出/启动报告/UART 前后比较不变 |
| Flash / 热替换 / 自动应用 | 编排器与适配器均为 Host 程序，无 Flash API、无运行时替换、无持久化；ARM 镜像不含它们 |

**当前不允许 Board Recorded 进入 ADC Candidate。** 本轮未修改该信任边界；改变它须另开授权任务，说明信任主体、来源证明、错误接纳风险与兼容性。

## 4. ADC_ZERO 与 Encoder 完整性的耦合

`observations()` 的 `complete` 同时要求：处置为正常封存、ADC 恰好 40 行、Encoder 恰好 16 行、无溢出、无无效 ADC 行、无 Encoder 错误或缺 RX、槽/Token/Encoder 序号无缺口或重复、计数器不增长。`prepare_trace` 要求 `complete`，否则 `ACQUISITION_INCOMPLETE`。

离线实测：ADC 40 行完整而 Encoder 缺 1 行时，无见证导入为 `DIAGNOSTIC_OBSERVATION`、`complete=False`、`ADC_ZERO=ACQUISITION_INCOMPLETE`；附见证则 `ACQUISITION_INCOMPLETE` 拒绝。Encoder 帧错误、序号缺口、SPI 超时同样阻断 ADC_ZERO。

结论：这是 Capture V1 会话完整性要求，不是 ADC 估计器的数学必需条件。当前软件不区分"ADC 有效但 Encoder 缺失"与"整个 Capture 不合格"，无 Encoder 夹具只能得到不完整诊断。按要求只记录现状，未放宽 Capture V1 资格。
