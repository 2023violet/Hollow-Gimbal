# 电机实机调试安全协议与开环排障流程

> 状态：当前实机调试的强制操作规程与后续固件安全实现要求
>
> 适用对象：Board1、AT32F415、DRV8311H、2804 BLDC 云台电机
>
> 编制基线：2026-08-27 当前工作树、Board1 原理图/网表、DRV8311H 资料和历史调试记录

## 1. 文档目的与当前结论

当前首要问题不是速度环参数，而是电机即使处于电压开环阶段也不能平滑运行，表现为卡死、定子电流偏大、线圈和驱动板持续发热。这个状态不能继续用“多运行一会儿再观察”的方式调试。

本文件同时定义两件事：

1. 电机上电、启动、运行和停机时必须遵守的安全协议；
2. 从电压开环重新建立证据链，再逐步进入 I-f、编码器零点和闭环速度控制的排障顺序。

本文件中的“立即停机”不是等待串口、VOFA、PC 或人工分析后的停机。实时路径只能执行固定的阈值比较、故障锁存和 PWM 关闭；原始数据保存后，在电机已经停止、母线已经断开或确认安全的状态下再分析。

### 1.1 当前调试状态

- `[现状]` 电压开环尚未达到“低电流、可控、连续旋转”的入口条件，不能继续进入闭环速度调参。
- `[历史验证]` CSAREF 修复、极对数修复、电流符号修复和 I-f 同步旋转曾经获得过历史实机证据；这些证据不能替代当前每次上电前的安全检查。
- `[历史基线，已更新]` 初版协议编写时 `foc_fault_check()` 为空；当前见第 13 节，已增加 ADC 快速故障路径和 1 ms 后备检查，但硬件 Break/nFAULT/独立断电仍未闭环。
- `[当前缺口]` 原理图中的 `nFAULT`、`nSLEEP` 没有 MCU 直接端点。DRV8311H 内部保护仍可能动作，但 MCU 当前不能可靠地读取故障并完成软件联动。
- `[当前缺口]` `pwm_out_disable()` 只关闭 TMR1 六路 PWM 通道，不等于切断 DCBUS，也不等于控制 DRV8311H 的 nSLEEP。
- `[协议]` 在上述缺口关闭前，任何实机运行都必须使用保守电源限流、短时单步实验和手边可立即操作的母线断电开关；不得无人值守运行。

## 2. 强制安全原则

以下规则优先级高于调试效率、波形完整性和参数收敛速度。

### 2.1 运行中只做保护，不做深度分析

运行期间允许执行的动作只有：

- 采集必要的原始 ADC、状态和控制量；
- 与预先加载的阈值做固定时间复杂度的比较；
- 置位故障原因和停机锁存；
- 关闭 PWM、清零占空比/设定值/积分器；
- 将最近一段数据写入 RAM 环形缓冲区；
- 触发或记录一次停机事件。

运行期间禁止：

- 等待串口、VOFA 或 PC 回复后再停机；
- 在 ISR 中打印文本、格式化浮点数、写 Flash 或执行阻塞 SPI；
- 为了“看完整波形”而继续保持高电流；
- 由调试脚本自动重启、自动清故障或自动重新上电；
- 让模型或人工分析成为唯一的安全保护。

### 2.2 3 s 是最大容忍时间，不是延迟停机时间

“电流/电压/转速持续 3 s 异常”必须解释为：

- 对于超过硬限值的严重异常：第一次有效采样发现就停机，不等待 3 s；
- 对于低于硬限值但持续偏大的警戒量：从第一次进入警戒区开始计时，最长不超过 3 s，达到上限立即停机；
- 对于 ADC 无效、NaN/Inf、母线失效、编码器失联、控制看门狗失效或 PWM 状态不一致：直接停机；
- 如果异常趋势明显上升，即使尚未达到 3 s，也应立即停机，不得为了凑满 3 s 继续运行。

因此，保护检查应在最快可用的控制节拍中完成；3 s 只用于给“尚未达到硬限值但明显偏大”的状态设置绝对上限。

### 2.3 每次实验必须有硬截止时间

在开环尚未通过前，每次上电实验都必须预先写明：

- 实验目的；
- 运行模式和唯一变量；
- 目标电压/电流/电角速度；
- 硬限值和警戒限值；
- 自动停止时间，初始实验不超过 3 s；
- 停机后的数据保存位置和判定方法。

没有这些内容时，实验状态为“禁止上电”。

## 3. 停机体系与责任边界

### 3.1 停机层级

```text
ADC/FOC 快速采样
    │ 过流、母线异常、非法数据、命令/占空比异常
    ▼
快速故障锁存 / TMR1 硬件 Break（若已接入）
    │ 立即关闭六路 PWM
    ▼
FAULT 状态 + 清零设定值/积分器 + 冻结 RAM 诊断快照
    │
    ├── 1 ms 任务：补充超时、温度、状态一致性和 3 s 持续异常保护
    ├── 5 kHz 编码器节拍：超速和编码器有效性保护
    ├── PC/VOFA：只负责记录，不拥有停机权限
    └── 操作者：发现冒烟、异味、持续升温或电流不衰减时立即断母线
```

### 3.2 当前代码能做什么、不能做什么

当前状态机已经存在一条可复用的故障停机动作：

- `EV_CMD_DISABLE` 路由到 `FAULT`，而不是 `IDLE`；
- `_on_fault_enter()` 将 `axis_state` 置为 `AXIS_STATE_FAULT`；
- 调用 `pwm_out_disable()` 关闭 TMR1 的 CH1/CH1C、CH2/CH2C、CH3/CH3C；
- 清理 PID、设定值和 `foc_calc`，避免旧占空比再次输出。

但这条路径目前主要由任务/FSM 触发，不能把它当作已经完成的快速保护。原因是：

- `foc_fault_check()` 的任务级策略已恢复，但当前仍依赖软件采样，不能替代硬件 Break；
- ADC ISR 已增加快速检查，任务级检查仍允许最多约一个 1 ms 周期的后备延迟；
- `state stop` 进入 `IDLE`，而 `IDLE` 会调用 `pwm_out_enable()` 并设置 0% 占空比。0% 输出是低侧钳位/主动短路语义，不等于桥臂三态关闭；
- `pwm_out_disable()` 不会切断外部电源，不能替代实验台上的电源急停；
- 当前没有 MCU 可用的 nFAULT/nSLEEP 直接控制边界。

因此后续固件实现必须区分：

| 动作 | 用途 | 是否可作为紧急停机唯一手段 |
| --- | --- | --- |
| `state stop` | 正常受控停止、进入 IDLE | 否；可能进入 0% 低侧钳位 |
| `state disable` / `FAULT` | 禁止输出并锁存故障 | 仅在命令链和任务路径健康时可用，不能替代快速路径 |
| 快速故障锁存 + PWM/TMR Break | 控制器内部第一响应 | 是软件/定时器层的必要路径 |
| 实验台 PSU 输出关闭 | 最终切断母线能量 | 是操作员必须保留的独立后备手段 |

## 4. 触发条件定义

所有阈值必须在启动前加载并通过合法性检查。阈值缺失、为 0、为 NaN/Inf、单位不一致或超出硬件能力时，系统必须拒绝进入 RUNNING，而不是使用默认值继续试转。

### 4.1 立即停机条件

下列任意条件成立，下一次可用的快速控制节拍必须置位故障并关闭 PWM：

1. 任一相电流、`Id/Iq`、母线电压、占空比、角度或速度为 NaN/Inf；
2. 任一相电流超过 `I_hard`，或 `sqrt(Id² + Iq²)` 超过硬限值；
3. 母线电压超过 `Vbus_ov_hard`、低于 `Vbus_uv_hard`，或母线无效但仍存在非零电压/电流命令；
4. 速度绝对值超过 `omega_hard`，或编码器数据非法、长时间不更新、跳变超出物理可能范围；
5. FOC 计算返回非法结果、SVPWM 占空比超出 `[0, 1]`、或 PWM 输出状态与控制状态不一致；
6. 检测到 DRV8311H 故障输入（未来完成硬件连线后）；
7. 任何软件看门狗、控制周期心跳或紧急停机锁存失效；
8. 操作者发现电机卡死且电流没有立即下降、驱动器/电机异常发热、异味、冒烟或声音异常。

对于第 8 项，操作者不需要等待软件确认，直接关闭 PSU 输出或断开母线。

### 4.2 持续异常停机条件

以下状态未超过硬限值时可以短暂记录，但必须从首次出现时开始计时：

- `I_warn ≤ |I| < I_hard` 持续偏大；
- `Vbus` 长时间接近上下限；
- 速度、角度或电流误差持续不收敛；
- 开环角度持续推进但转子不跟随，且电流持续高于警戒值；
- 控制命令非零而机械速度长期接近零；
- 遥测/控制心跳丢失。

持续时间到达 3 s 前必须停机；硬件热惯性、线圈温升和驱动器保护不能作为延长运行时间的理由。

### 4.3 阈值单位必须固定

当前工程中存在多种速度和频率单位，后续每次实验记录必须显式写单位：

- 电流：A，明确是相电流峰值、RMS 还是 `Id/Iq` 矢量幅值；
- 母线：V；
- 机械速度：输出轴 rad/s 或 rpm；
- 电气速度：电气 rad/s 或 Hz；
- 电角度：rad，范围和正方向明确；
- 电压命令：V，明确是 `Vd/Vq`、相电压还是母线归一化占空比。

7 对极电机若电气频率为 300 Hz，机械同步转速应约为 2571 rpm；若机械速度约为 43 rpm，则对应电气频率约为 5 Hz。因此历史记录中的“300 Hz 与 43 rpm”不能直接作为验证基线，必须先确认 `we` 的真实单位。

## 5. 故障快照与停机后分析

### 5.1 快速路径的数据要求

快速保护路径只保存固定大小、无阻塞的 RAM 快照。建议每个采样点至少包含：

```text
timestamp / sample_counter
axis_state / ctrl_mode / input_mode
fault_code / trip_reason / trip_latched
raw_adc_vbus / raw_adc_ia / raw_adc_ib / raw_adc_ic
v_bus / ia / ib / ic / id / iq
id_set / iq_set / vd / vq
theta_elec / encoder_raw / encoder_valid
dtc_a / dtc_b / dtc_c / sector
velocity / temperature_if_available
```

环形缓冲区应保留触发前最近一段数据，并在故障触发时再冻结触发点及少量后续状态。保存动作不得擦写 Flash，不得阻塞 PWM/ADC ISR。

### 5.2 运行期间与停机后的职责分离

| 时机 | 允许做的事情 |
| --- | --- |
| 电机运行中 | 阈值比较、故障锁存、PWM 关闭、RAM 快照、最小状态计数 |
| PWM 已关闭但母线仍在 | 确认电流衰减、确认状态为 FAULT、禁止自动重启 |
| PSU 已关闭且电机停止 | 输出/导出快照，解析波形和故障前后窗口 |
| 完成分析后 | 只在确认原因、重新设定限值并清除锁存后，才允许下一次短试验 |

串口和 VOFA 只承担“搬运已冻结数据”的职责。实时路径不能依赖串口可用性；串口断开时，停机仍必须发生，数据保存在 RAM 或下次安全导出介质中。

## 6. 当前问题的分阶段排障流程

当前必须退回到“开环最小闭环证据”，不能直接继续调速度环或反复修改 `encoff`。

### 阶段 0：软件与输出安全自检

目标：确认没有实机输出时，所有保护和停机动作的逻辑边界清楚。

- 验证 `FAULT` 状态会关闭六路 PWM、清零设定值和控制变量；
- 验证故障锁存后不会被普通 `START` 自动清除；
- 验证非法阈值、非法 ADC、零母线和 NaN/Inf 会拒绝 RUNNING；
- 验证 3 s 持续异常计时器不会溢出，也不会因一次正常采样错误清零；
- 使用主机测试验证快照格式、触发原因、锁存和导出解析；
- 该阶段不连接电机、不接触实板，属于无板验证。

### 阶段 1：仅验证采样和电压换算

PWM 保持关闭，只验证软件对 VBUS、IA、IB、IC 的换算和范围判断。

- CSAREF 必须被视为电流采样零点的一部分；
- GAIN 的真实硬件配置未确认前，不能用未经核实的 `0.5 V/A` 作为唯一保护依据；
- ADC 原始值越界、偏置突变或三相 KCL 明显不一致时，禁止进入下一阶段；
- 不允许通过提高电压来“观察采样是否正常”。

### 阶段 2：最小幅值固定定子矢量

目标：验证单个 `dp0/dp1/dp2` 定子轴与相位输出的关系，不要求旋转。

- 只允许一个固定轴、一个很小的电压/电流命令；
- 运行时间短于 3 s，电流超过警戒值立即停；
- 记录三相电流、`Id/Iq`、占空比和实际状态；
- 如果固定矢量下电机直接卡死且电流大，不能通过继续加压“克服卡死”，应回到相序、采样符号、CSAREF、坐标变换和电角度边界检查。

### 阶段 3：低幅值、低速电压开环扫角

目标：先证明电压开环本身可以连续推进，不接管编码器闭环。

- 电角度以已知方向、已知单位、低加速度推进；
- 电压幅值从最小值逐步增加，每次只改变一个变量；
- 转子不跟随而电流升高时，立即停机；
- 转子只抖动、反复翻转或停在一个点时，判定为开环失败，不进入速度环；
- 通过停机后的快照判断是相位映射、采样极性、角度方向、饱和、母线换算还是电机本体参数问题。

### 阶段 4：低幅值 I-f

I-f 仅用于证明“电流幅值受控 + 开环电角度推进 + 电机能跟随旋转磁场”。它不能证明编码器电角度零点正确。

- 先固定低电流，再使用低电气速度；
- 速度单位必须同时记录电气单位和按 7 对极换算后的机械单位；
- I-f 运行平滑只说明基本功率级、SVPWM 和电流反馈链路具备工作证据；
- I-f 仍出现卡死和高电流时，首先检查开环路径，不再把问题归咎于 `encoff`。

### 阶段 5：编码器原始方向与零点

PWM 关闭时验证编码器原始角度、方向、单圈回绕和 LUT 是否合理；然后才进行零点校准。

- 先建立“编码器原始角度 → 机械角 → 电角度”的单一公式；
- 先确认方向，再确认零点；方向错误时，单纯修改 `encoff` 不能修复坐标系；
- LUT 可能改变空间角度关系，必须提供关闭 LUT 的原始线性基线；
- `encoff` 试验一次只改变一个方向和一个步长，并保留每次停机快照；
- 在几何关系没有证明前，不执行 `store save enc` 固化参数。

### 阶段 6：小范围闭环速度

只有阶段 3 和阶段 5 都通过，才允许进入闭环速度。

- 速度命令从零开始，限制最大 `Iq` 和最大速度；
- 先验证低速正向，再验证低速反向；
- 任何“转子吸附、Iq 打满、速度不跟随”的组合都立即停机；
- 闭环调参期间不保存参数，直到同一组参数连续通过多次短试验；
- 速度环的成功不能覆盖开环阶段的失败，必须保留各阶段独立证据。

## 7. 实机操作清单

### 7.1 上电前

- 电机机械固定，转子周围无可能被卷入的物体；
- PSU 电压、电流限值已记录，输出关闭开关在手边；
- 示波器/万用表探头不会造成短路；
- 已确认当前实验的唯一变量、运行时间和阈值；
- 固件构建版本、配置摘要和 Git 工作树状态已记录；
- 自动启动、自动重试、自动清故障和自动保存均关闭；
- `CSAREF`、电流 GAIN、VBUS 分压和 ADC 通道映射已有证据；
- 串口/VOFA 仅作为日志通道，不作为停机保障；
- 如果任何阈值或单位不确定，禁止上电。

### 7.2 运行中

- 只运行一个短实验，不同时改变电压、速度、方向和滤波器；
- 不把手放在电机、转子或裸露功率节点附近；
- 看到卡死、高频抖动、异常声、电流上升、母线异常或温升加快，立即断电；
- 不等待 3 s，不等待 VOFA 刷新，不等待分析结论；
- 软件停机后仍确认电流已经衰减、PWM 已关闭，再关闭仪器连接或触碰硬件。

### 7.3 停机后

- 先记录停机原因、实验命令、阈值、母线设置和运行时长；
- 保存 RAM 快照/串口原始日志，不覆盖上一次失败样本；
- 对电机、DRV8311H 和 PCB 做温度/气味/外观检查；
- 在确认安全后再分析电流、占空比、角度和速度；
- 每次只形成一个可证伪的假设，下一次只改变一个变量；
- 未定位原因前，不通过增大电压、电流或延长时间来“验证能否转起来”。

## 8. 无板验证要求

本文件的安全协议可以先通过无板方式验证，但无板测试不能证明真实电机已经安全。

必须覆盖以下软件行为：

| 场景 | 无板判定 |
| --- | --- |
| 电流超过硬限值 | 同一模拟采样窗口内产生 trip，PWM 状态变为 disabled |
| 电压/速度超过硬限值 | 不等待 3 s，立即锁存对应 fault bit |
| 警戒值持续 3 s | 到达 3 s 时 trip，3 s 前不会被错误延长 |
| 警戒值中间恢复 | 按明确定义清除计时；不允许计时器异常溢出 |
| ADC 为 NaN/Inf/越界 | 立即 trip，不能产生 Inf/NaN duty |
| 零 VBUS + 非零命令 | 先 trip，不能执行 `1.0f / v_bus` |
| 故障期间 START | 被拒绝，不能自动重新使能 PWM |
| 故障重复触发 | trip 幂等，不能重置快照或重新打开 PWM |
| 串口/VOFA 不可用 | 保护仍动作，日志保留在 RAM |
| 正常 STOP 与紧急 DISABLE | 分别验证 IDLE 低侧钳位语义和 FAULT/PWM disable 语义 |

无板验证至少应包含：

- 固定点/浮点阈值比较边界测试；
- FOC/SVPWM 非法输入和饱和测试；
- 故障锁存、清除和禁止自动重启测试；
- 3 s 计时器测试；
- 触发前后环形快照和二进制日志解析测试；
- 当前 AT32F415 固件交叉编译和主机契约测试。

## 12. 2026-08-27 实机只读调试记录

> 本节记录安全实现刷写前的首轮只读基线；实现后的复核和当前状态见第 13 节。

### 12.1 测试边界

- 设备：AT32F415 + DRV8311H Board1，调试器为 CMSIS-DAP/DAPLink，串口证据来自 COM3。
- 电源：外部电源设为 12 V / 1 A；空载母线实测约 11.88–11.90 V。
- 本轮只执行 SWD/串口只读检查，以及停留在 IDLE 时的 RAM 临时校准调用；没有发送 `state start`、电压注入、I-f 或电机校准命令，没有烧录 Flash。
- 当时 G0 未解除：首版固件既没有快速故障锁存，也没有已证明的独立功率切断路径；当前软件快速锁存已落地，但由于硬件急停路径仍未证明，G0 仍不允许电机通电驱动。

### 12.2 现场证据

| 项目 | 结果 | 判定 |
| --- | --- | --- |
| SWD 连接 | DPIDR `0x2ba01477`，识别到 Cortex-M4 r0p1 / AT32F415 | 调试链路正常 |
| 轴状态 | `axis=idle`，`ctrl=volt`，`input=inactive`，`fault=0` | 没有进入驱动态 |
| 母线 | `vbus=11.9 V`；SWD 快照约 `11.905 V` | 电源读数正常，不能代表负载安全 |
| ADC 原始相电流 | IA/IB/IC 约 `2051/2053/2051` | 均接近 12-bit 中点 |
| 当前零点 | IA/IB/IC 约 `2048.1409/2051.5095/2047.8881` | 零点当前合理 |
| 换算相电流 | 约 `-4.6/-2.4/-5.0 mA` | 当前无明显假电流 |
| TIM1 | `PR=3749`，CH1–CH3 比较值为 0，CH4 比较值为 3740 | 三相零占空比，但通道仍使能 |
| Break/主输出 | `BRK=0x8000`，Break 输入未启用、死区配置为 0 | 不能作为安全切断证明 |

TIM1 的当前状态必须解释为“低侧钳位的 IDLE”，不是高阻态或 DCBUS 断开。若需要真正的紧急停止，必须进入 FAULT、关闭 PWM，并由外部电源或独立硬件路径切断功率。

### 12.3 已证实的根因链

本轮首次状态快照中，ADC 原始值仍在约 2050 附近，但电流零点曾为 IA/IB/IC `3664.3904/3241.6584/2321.573`，于是当前换算式

```text
Iphase = -(ADCraw - ADCoffset) × 3.3 / (4095 × 0.5)
```

直接产生约 `2.60/1.92/0.44 A` 的假相电流。随后在 IDLE 状态下只写入 RAM 临时零点 `2052/2051/2049`，换算电流立即回到约 `-4.8/-3.2/-1.6 mA`；恢复旧值后假电流又回升。该可逆因果实验证明：当前“电流高”的第一直接原因是错误或过期的电流零点，不是 12 V 母线读数或 ADC 通道映射本身。

当前调用一次 `foc_calib_curr()` 后，零点稳定在约 2048 附近，现场电流回到毫安级。但“为什么上电自动校准第一次得到错误零点”还没有在不冒险复位的前提下完成复现；候选边界是 DRV8311H 电流检测模拟链上电稳定时间、PWM/低侧采样窗口和启动时序。不能把这个候选原因写成已证实事实。

### 12.4 解除实机驱动前的硬阻塞

- （实现前基线）`applications/runtime/motor_fault_runtime.c` 中 `foc_fault_check()` 当时为空，严重过流、欠压、过压、超速和非法数据没有软件实时故障生产链；实现后状态见第 13 节。
- 原理图网表显示 DRV8311H 的 `NFAULT`、`NSLEEP` 没有连接到 MCU 端点，当前固件无法用它们完成故障反馈或硬件睡眠控制。
- `wk_tmr.c` 配置 `brk_enable=FALSE`、`deadtime=0`；必须先完成死区、Break 和门极波形的独立验证。
- `pwm_out_disable()` 只关闭六路定时器通道，不切断 DCBUS；`12 V / 1 A` 电源限流也不是相电流限流器。
- USART1 同时承载 Shell 文本和 VOFA JustFloat，原始串口日志会被二进制帧污染；保护逻辑不能依赖串口分析。

### 12.6 会话安全收尾

本轮结束时发送了唯一的安全状态命令 `state disable`。串口返回 `axis=fault`，SWD 读到 TIM1 `CCTRL=0x1000`：CH1–CH3 的主/互补输出使能位均已清零，仅保留 CH4 作为 ADC 触发源；故障掩码为 0，说明 FAULT 是本次主动禁用锁存，而不是新增的硬件故障。由于 `pwm_out_disable()` 不切断 DCBUS，若不继续立即测量，应再物理关闭 12 V 电源。

## 13. 2026-08-27 安全实现后的复核记录

### 13.1 快速停机闭环已落地

本轮已经把第 10 节中“故障检查为空”的历史阻塞落实为可验证实现。当前 ADC 中断顺序为：

```text
adc_read_phases()
  -> foc_fault_check_fast()
  -> fault_code != 0 ? return : half-div / foc_current_loop_step()
```

`foc_fault_check_fast()` 只在 `RUNNING`/`CALIB` 生效，执行有限性、每相电流、VBUS、输出速度和温度检查。硬故障直接锁存故障位并调用 `pwm_out_disable()`，不打印、不等待、不写 Flash、不切换 `axis_state`；因此故障发生后本次 ISR 不会继续由 FOC 重写 PWM。状态机仍在任务上下文中完成 FAULT 迁移。

当前 bring-up 诊断包线为（基于电机资料的 `0.5 A` 额定、`2.0 A` 最大值的临时值，
不是产品热稳定性认证）：

| 条件 | 门限/动作 |
| --- | --- |
| 每相快速过流 | `abs(Iphase) > 1.00 A`，首个 ADC 快速样本 trip |
| 任务级持续电流 | `sqrt(Id²+Iq²) > 0.75 A` 持续 `3000 ms`，锁存过流 |
| 低速堵转 | 仅闭环模式：有驱动命令、`sqrt(Id²+Iq²) >= 0.75 A`、输出速度 `<=5 rpm` 持续 `200 ms`，锁存过流 |
| 母线 | 产品运行时阈值 `7.4 V / 17.0 V`；非法/非有限值为传感器故障 |
| 输出超速 | 使用现有 `vel_over_thr`，首个快速样本 trip |
| 温度/数据 | 非有限值立即 trip；温度超过已启用阈值立即 trip |

配置的 `i_peak=2.0 A` 不能绕过 `1.00 A` 的临时 bring-up 快速上限；若配置了更低的正
`i_peak`，快速门限只会进一步降低。所有 trip 都是幂等的，避免重复关闭 PWM。电压开环
不使用 `5 rpm/200 ms` 闭环堵转判据，固定矢量和旋转矢量仍受每相快速过流与 3 s 持续电流
保护约束。

### 13.2 启动电流零点校准已加安全边界

`foc_calib_curr()` 现在执行：

1. 关闭六路桥臂输出；
2. 等待模拟前端稳定 `100 ms`；
3. 每 `1 ms` 采样一次，共 `2000` 个样本；
4. 对 IA/IB/IC 分别做 Welford 均值/标准差统计；
5. 要求均值在 `64..4031`、标准差不超过 `16 counts`；
6. 任一相失败则锁存 `FAULT_CALIBRATION_FAILED`，保持 PWM 关闭，不写入无效 offset；
7. 全部通过后按现有 `ABC/ACB` 相序写入 offset，再恢复零占空 IDLE 钳位。

该流程直接针对现场已证实的因果链：raw ADC 约 2050 而旧 offset 为约 3664/3242/2322 时，换算电流会被伪造成安培级；将 offset 临时改到 raw 中点后，电流立即回到毫安级。新校准策略能拒绝 rail、NaN/Inf 和噪声过大的样本，但不能替代对 CSAREF、DRV8311H 上电稳定时间和采样窗口的示波器验证。

### 13.3 VBUS 非法值保护

`foc_para_calc()` 在 `1.0f/v_bus` 和 PID 电压限幅前检查 `isfinite(v_bus) && v_bus > 1.0f`。`foc_ctrl_volt()` 对同一条件再次检查；失败时清零电压/占空比并关闭 PWM。数值防护只负责阻止 NaN/Inf/零除传播，欠压/过压的产品判定仍由运行时故障策略完成。

### 13.4 本轮验证状态

其中涉及实板只读/刷写的条目分为历史证据和 2026-08-29 受控短脉冲证据；两者都不能解除产品级实机门禁。

- 无板安全/参数目标：快速故障、校准判定、VBUS 判定和 FOC 参数应力模型 4 项均 `PASS`。
- 完整 host flow：当前 35 个目标全部编译并通过 CTest（最终门禁以本轮新鲜输出为准）；fail-fast、任务栈、FSM 中止、动态 LPF、故障上下文、运行态诊断门禁、带电校准门禁、诊断格式和 FOC 参数/开环模型契约均已完成回归，软件门禁通过但不替代功率级硬件门禁。

本轮已增加受控短脉冲实板数据，但只证明“当前 bench 镜像在极短低压窗口内能执行开环并由板上 ADC 返回低电流”。以下证据仍未完整形成：DRV 门极死区、Break 硬件切断、nFAULT 软件反馈、外部电源断开响应、示波器波形、独立相电流、热稳定性、电机低速同步和持续旋转。因此不得因为短脉冲或历史 offset 记录就提高供电限流、无人值守运行或进入闭环调参。

## 18. 2026-08-30 正交矩阵的安全执行边界

`[源码确认]` 新增矩阵使用 64 条 FOC 定点 ring、32 条编码器 ring 和 bench-only map/

## 19. 开环测试参数校正（2026-08-30）
