## 3. 启动策略 A/B/C 和选择

在隔离副本使用相同审核指纹、目标和 Plant，只替换策略。A 是当前 130 Hz。B 启用现有 `−ωe Lq Iq` 和 `ωe(Ld Id+ψf)` 前馈，Ld/Lq/磁链均来自审核过的虚拟测量，采用现有相位、源年龄、数值和电压准入。该前馈在静止时为零，并且没有电阻或指令变化项。B 未通过后试验 C，只在一次新限流后目标变化时施加一拍 `L·ΔI/360 µs`，电压向量界 0.40 V。保留既有调制、抗饱和及试算提交。试验性历史在 START 清零，拒绝 UPDATE 时随试算丢弃。C 的数据和源码保留为实验。两个候选均未进入生产。

实验预先规定名义正反向在两配置至少改善一个 200 µs H0，候选不能换取新的限幅或保护失败，留出退化不超过一拍，精度和超调的额外容差各 0.02 A。下表使用实验的 20 ms 分段与 ±0.04 A 连续 2 ms 保持口径。它与 V1 的 60 ms 全窗和幅值相关误差带分开。

C 将 Generic 正向名义首拍 q 电压从 0.598 V 升至 0.998 V，使 20 ms RMS 从约 81.64 降至 76.45 mA，却延长达到同一保持条件的时间。B 在预转时既有收益也有退化，受限反向退出还可多用 400–600 µs。名义 A/B/C 均无电压削顶，强制低压试验各有 100 拍受限，未改变准入。两种相反 R/L 失配和正反向的完整积分、跟踪、实际 Core 饱和位及伏安波形在原始包。STOP、超时、陈旧 H1、持续 Encoder FAULT、拒绝首次 UPDATE 及 B/C 的 NaN 模型负向用例均按合同结束。拒绝后试验性状态及 PI 未提交。

C 的第一次响应更快。以 Generic 正向为例，2,200 µs 的 Iq 从 0.07638 升为 0.12764 A。随后的比例误差和积分累积较小，4,800 µs 时 Iq 反而从 0.41091 降为 0.40449 A，同拍 q 积分从 0.24799 降为 0.23422 V。预转使用 Host 禁用时的零端电压模型，首次 UPDATE 前已经存在约 ±0.18 A 的反向电流，该比较适用于这一初始状态。

补充试验保持 ±2.20 A 完整 60 ms，沿用 V1 的 0.22 A 误差带。Generic A/B/C 均为 3.4 ms，均约 0.4 ms 近限压。Salient A/C 仍为 4.8 ms 且尾段近限压，B 无最终保持后缀，近限压增至 16.4–16.6 ms。十二个运行均确认 300 次有效更新并正常 STOP。大电流的尾段容量问题未由候选解除。

历史 10 ms 三点 0.3253 / 0.1953 / 0.1176 A 仍复现。CQ-02 的独立 PI/ZOH 模型在三个点与观察相差不超过 0.2542 mA。首个样本仅经历 200 µs 施压，0.5832 V 产生的 RL 瞬态足以解释误差。同一 2.4 V 上限的理想模型首点可以达到带内，故原工况是控制律、首拍电压设计与电机动态的取舍。现有仿真没有多余的命令或实际输出延迟。历史全窗 0.152791 A RMS 和 RUNNING 0.089169 A RMS 仍保留，STOP 后零有效输出。

Impedance 每拍重算 PD，外环没有积分。当前矩阵零电压削顶，最新 H1 目标与每个匹配 H0 请求一致。近边界 q 积分约 ±0.149 V，卸载进入误差带时趋于反号约 ∓0.021 V。Velocity PI 的方向抗饱和和信号提交使用既有机制，Position 的 P 输出受限后进入同一 PI。另行复跑 Velocity/Position 正反向、0.025 N·m 扰动和卸载、Encoder FAULT、模式切换和状态复位，未发现可复现的目标滞留或抗饱和缺陷。
