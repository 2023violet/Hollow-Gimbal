可选参数 `-DFALCONFOC_RT02_TIMING_TRACE=ON` 在启用 IRQ 前尝试启动 DWT CYCCNT。现有事务携带 `slot_id`、`generation`、既有 TMR2 请求/完成时间和新增 cycle 点位。一份 live、一份既有单读者快照，采样和发布有界。只记录当前事务，无高频 ISR 打印。OFF 在预处理期裁掉插桩，默认固件也没有运行候选合同。

## 5. 单 ADC 四 Rank 与模拟窗口

当前 HCLK=150 MHz，PCLK2=75 MHz，ADC /6=12.5 MHz，1 ADC cycle=80 ns。7.5-cycle 采样孔径 600 ns，12.5-cycle 转换 1,000 ns。DS Rev 2.02 表 44 的抢占触发延迟上限为 3 ADC 时钟（本配置 240 ns），外部触发再加一个 PCLK2 时钟（约 13.3 ns）。下表从生效的 SOC 开始，未加入这段同步延迟或 PCCE 响应。 [AT32F415 数据手册 §5.3.19](https://www.arterychip.com/download/DS/DS_AT32F415_V2.02_EN.pdf) · [RM §18.4.2.3](https://www.arterytek.com/download/RM/RM_AT32F415_V2.05_EN.pdf)

| Rank / 实际引脚 | 孔径开始 µs | 孔径结束 µs | 转换完成 µs |
| --- | ---: | ---: | ---: |
| 1 · VBUS · PA1 / IN1 | 0.0 | 0.6 | 1.6 |
| 2 · IC · PA4 / IN4 | 1.6 | 2.2 | 3.2 |
| 3 · IB · PA5 / IN5 | 3.2 | 3.8 | 4.8 |
| 4 · IA · PA6 / IN6 | 4.8 | 5.4 | 6.4 |

相邻相差 1.6 µs，IC 到 IA 相差 3.2 µs。四 Rank 的孔径和有效电压范围各自核对。VBUS 还要考虑分压网络源阻抗、噪声、前 Rank 残留以及 ADC 采样电容（DS 表 44 典型 15 pF）。当前没有改变 rank 的测量依据。

Board1 用 DRV8311H 三路内置低侧 sense FET / CSA，SOA/B/C 经 330 Ω / 22 pF 到 ADC；这个外部 RC 的标称小信号时间常数 7.26 ns。TI 数据表给出指定 SOx 阶跃及 30 pF 条件下典型 1 µs 的 ±1% 建立时间，并指出低侧取样动态偏置或增益受工况影响。该典型值、保护消隐和外部 RC 各对应不同物理量。需对装配版本、驱动及 MCU dead time、换向/衰减、振铃、模拟建立和 ADC 采样保持误差取得实际边界。 [Board1 硬件 Wiki](../code-wiki/hardware-and-drv8311h.md) · [原理图](<../pcb docs/pcb原理图.pdf>) · [DRV8311 §7.5、§8.3.10 与 §10.2.1.4](https://www.ti.com/lit/ds/symlink/drv8311.pdf)

模型用周期 `T`、逐相高侧占空比 `d_i`，假设中心对齐、高侧在计数谷附近导通、低侧在计数峰附近导通。对第 i 相，

```text
c_i = d_i · T / 2
ideal_low_i = [c_i, T − c_i]
usable_i    = [c_i + g_after_i, T − c_i − g_before_i]
rank_i is usable iff usable_i fully contains [aperture_start_i, aperture_end_i]
```

`g_after_i` 包含有效开通延迟、dead time、需要避开的瞬态、CSA/RC 建立及相位误差裕量；`g_before_i` 包含关断前的观测和相位裕量。S&H 吸合和输入源阻抗还须满足 ADC 误差预算。不同相各算各的窗，`d_i→1` 时可用窗口收窄。用纯 C11 覆盖逐相窗通过、单相高占空比失败及整组太迟三个例子。若台架证明 VBUS 领先 1.6 µs 造成三相边界失败，可另评估 IC/IB/IA/VBUS，把三相整体提前 1.6 µs，偏移仍为 3.2 µs。拟变更需回归 PA→逻辑相映射、ADC 校准与 VBUS 保护、相位与同槽时间合同，再按实测验证采样误差。

## 6. PWM Shadow-to-Active 合同与频率预算

未来功率载波从各自选定的基准边界编号；阶段时间使用 `{cycle, phase_ns}`。中心对齐采用从谷递增的时间相位，峰在 `T/2`，峰后是下数。来源是经映射的 RT-01 槽/generation，后续依序为同槽 EOC、H0 start、H0 finish、三相 shadow 写完、指定且经独立见证的装载。应用须给出 `(k+n, phase_load)` 及 setup；分频方案同样按单次更新选择这个装载点。本轮证明的 `n=0` 同载波峰及 `n=1` 下一载波谷属于 Host 事件，固件继续只反映逻辑时间槽。

```text
latest_H0_finish < t_load − t_setup − t_shadow_commit
ADC EOC ≤ H0 start ≤ H0 finish ≤ shadow_write < t_load − t_setup
```

期限相等判为失约。用真实 token 字段要求当前槽与 generation 相符、采样和 H0 消费有效、H0 成功、逻辑 UPDATE 获准，以及三相窗口合格。暂存产生 `STAGED`；装载观测还要精确匹配目标并在同一装载决策检查 STOP/FAULT 后的输出许可，然后产生 `MODEL_APPLIED`。过期、重复、错周期、权限撤销或事件不可判定会废弃 pending；后续装载不会复用旧候选。实际锁定 Board 适配器拒绝 UPDATE，正向装载案例中的适配器许可来自隔离的 Host 输入。未来实现须在期限前完成全三相 shadow 提交，并验证中途 STOP 的物理抑制权限。 [纯 C11 合同](../../firmware/at32f415/src/foc_board_timing.c) · [Host 期限测试](../../firmware/at32f415/tests/test_foc_timing.c)

RM §14.3.4 规定 TMR1 CH1–4 `CxOBEN=1` 时数据先存 buffer，合格 overflow event 才转移生效；关闭 buffer 时写入立即影响比较。中心对齐的峰/谷终点、`RPR`、软件更新事件、`OVFEN/OVFS` 和方向都影响最终事件选择或其可见性。将来的物理证据应绑定计数模式、配置和 PWM 波形，单独确定哪一侧终点传输，观测多相一致性和与写入的最小间距。 [AT32F415 RM §14.3.3、§14.3.4](https://www.arterytek.com/download/RM/RM_AT32F415_V2.05_EN.pdf)

以下用相位 +10 µs 作为统一的算术例子，每次更新选下一载波谷、假设 setup=2 µs。窗口仍须扣除从预期触发到生效 SOC 的延迟、EOC 到 H0 入口、抢占、三相写入及其他实测裕量。这个相位只用来说明预算关系。

| 候选 | 每载波 / 每次更新 | EOC 后至写截止的上限，未扣附加延迟 |
| --- | --- | ---: |
| 20/20 kHz | 50 µs / 50 µs | `50−2−10−6.4` = 31.6 µs |
| 10/10 kHz | 100 µs / 100 µs | 81.6 µs |
| 20/10 kHz | 50 µs / 100 µs | 31.6 µs，每隔一载波处理，单次写期限仍按指定的下一谷 |
| 20/20 同峰装载对照 | 50 µs / 50 µs；峰 +25 µs | 6.6 µs |

若在 50 µs 载波直接沿用 +40 µs，按下一谷、2 µs setup 只余 1.6 µs，尚未扣同步、IRQ 和写入。静态得知四 Rank 在 6.4 µs 完成名义转换，Host 得知可判定及时、迟到及缺失事件。两者都未给出 20/20 的实机采样窗口、相位一致性、调度响应上界或稳定性。降频或改变装载会改变数据年龄及闭环相位，需要结合实测评估。

## 8. 交接问答与 RT-03 输入

1. **软件触发抖动。** 主要候选机制是 CH4 到 ISR 的可变响应，加上 ISR 中标志、时钟夹读和 token 验证到 PCSWTRG 的经过时间。同优先级 ADC1 IRQ 占用、IRQ 屏蔽或异常上下文会影响响应。贡献及分布待 DWT 与独立事件测量。
2. **正确硬件触发路径。** 首选对照为专用 CH4 selector 0x01；0x06 配合 Remap7 bit 4 可选择共享 CH4。TMR1 TRGOUT 是可单独设计同步的路径，须先验证 PTOS 和实际相位。
3. **Legacy 异常根因。** 证实了历史生成配置的 TMR3_CH4 与口述 TMR1 路由差异，复现了握手跳档机制。角度相关增益的唯一物理根因未复现。
4. **继续验证哪条。** 保留当前软件触发作为基线，优先以专用 0x01 做经授权 A/B。它避免共享 GMUX 歧义，仍须证明事件方向、相位、来源与排空身份。
5. **四 Rank 是否进窗。** 可计算 6.4 µs 名义转换及 3.2 µs 相间偏移。随占空比收窄的实际有效窗口待板测，当前无法判定全工况覆盖。
6. **实际采样相位。** +40 µs 是编程比较相位；入口 CVAL、预写 CYCCNT、PCCE IRQ 都有各自代理意义。实机 aperture 仍无证据。
7. **H0 最晚何时结束。** 指定 `load − setup − 三相写入最坏经过时间` 之前。须按真实编程相位与有效装载事件重新预算。
8. **何时生效。** 缓冲启用后，由预定且合格的定时器装载事件使 active compare 生效。Host 能模拟同载波峰或下一载波谷，目标板还需波形见证。
9. **20/20 支持和阻断。** 50 µs 与 6.4 µs 能提供静态预算，Host 已验证事件判定。真实 SOC/CSA 窗、负载下 IRQ 响应、H0/H1/SPI 最坏时序和装载余量仍阻断频率晋级。
10. **必须上板的证据。** 芯片修订及路由/方向寄存器读回，触发事件与真实 SOC/PCCE 的边沿和计数，满占空/转速/电流条件的逐相孔径，写入到 active 的物理转移与三相一致性。
11. **RT-03 优先路径。** 首先校准 DWT/外部探针并测 CH4→PCSWTRG→PCCE→H0，覆盖正常 H0、有效 UPDATE 被锁定拒绝、STOP/FAULT、时间/样本错误、最重 PI/SVPWM 与预测年龄；随后覆盖 TMR5 启动/CS、+20 µs SPI 发送、SPI1 RX/error 与 +70 µs close 冲突、H1 解码/发布；最后在 H0 抢占 H1/SPI 与 USART 负载下量化响应分布、可验证的最坏上界、剩余 deadline slack 与栈高水位。保留相同的 SPI 帧、超时和测试负载；若出现可量化的瓶颈，再比较 SPI DMA。
12. **ARCH-00 是否须改判。** 保持 H0/H1/Foreground、独立 C11 Core、SPI IRQ 和 `sched KEEP_UNUSED` 的裁决。当前证据只支持 Board1 端的候选核验和监测。
