## 位置、速度与时间边界

四臂使用相同生产 H1、H0、Pipeline、Current 与 Safety。实验把滤波造成的阻尼项差值作为 Host 等效修正，通过现有前馈成员和同一个命令槽传入。物理模型前馈逐拍由 02C API 计算并独立记录。生产 Core 对弹簧、阻尼与合成前馈的总和实施既有转矩和 Iq 限幅；H1/H0 继续使用同一个源样本的原始电角与 Sensor 机械速度。修正仅在 Host 臂 B/D 生效。

仅过滤反馈时，阻尼速度差为 \(v_r-F(v_s)\)。相同初始化与采样时，它与过滤整个速度误差 \(F(v_r-v_s)\) 的差为 \(v_r-F(v_r)\)。使用实际归档 Sensor 值和真源时间，固定输入重放给出可复算的相位不一致转矩 \(D[v_r-F(v_r)]\)。三次窗口 **1.382 mN·m RMS**、峰值 **2.408 mN·m**，02C 五次参考窗口 **1.690 mN·m RMS**、峰值 **2.358 mN·m**。在缓变条件下，\(D\tau a_r\) 近似这一额外分量；48 Hz 的 \(\tau\) 约 **3.316 ms**，名义 D 下相当于 **0.000159 kg·m²** 的加速度比例项。这个诊断使用相同输入记录，无第二套闭环数据，也未作为调参依据。速度误差滤波仅用于拆解作用，唯一闭环候选固定为反馈支路 48 Hz。

Host 使用同原 Encoder source timestamp，并以最近一次 H0 确认的源时刻计算新滤波步长。原三次参考实际源间隔 464/536 μs。合法延迟组使用 99 μs 的提前采样、80 μs 的 H1 等待和 120 μs 的虚拟占空比待应用时间，最大获接受的源龄为 600 μs。超龄反例另从 1.220 s 注入。时间记录保留采集、H1、H0、提交与应用快照。
