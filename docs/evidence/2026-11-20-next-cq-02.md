## 2. 正式阻尼滤波与动态代价

Encoder 将原始连续机械角转换到已定义的机械坐标，生成相位和带源时标的估速。历史夹具的共同估速已经经过 80 Hz 低通。H1 用同一拍的位置、速度、帧身份和源时标生成阻抗目标，原 D 项直接乘以速度差，因而放大稳定保持时残留的高频速度噪声。Core 按 Kt、转矩和 q 电流上限算出限幅目标，H0 按同一份会话与时间身份检查并经 Safety/Pipeline 提交。噪声首先出现在 H1 的 q 请求，两项的 Plant q 高频 RMS 相对较低。

在 Runtime 采用 `F(v_ref−v_measured)` 一阶后向欧拉低通，只改变进入 D 项的速度差。实际捕获间隔 `Δt` 给出 `α = 2πfΔt/(1+2πfΔt)`，用 H1 私有的上次有效结果和本次速度差更新。K 项、前馈、原始估速、电角、H0 预测、时序和安全有效性消费既有值。正式链路继续由 Core 计算 D 与限制。单独滤反馈的 `v_ref−F(v_measured)` 经同一生产 H1 的隔离编译验证，虽能通过噪声门槛，却触发 **15 项冻结动态断言**。例如名义反向速度 RMS 从 0.014655 升至约 0.039097 rad/s，门槛为 0.023319。相位一致的速度差滤波给出 0.015521 rad/s。

- `motion.impedance.damping_filter_hz` 在 Runtime 初始化时校验，0 为旁路，1–200 Hz 为可配置范围。Control Plane 验证同一范围。H1 只在有效的 RUNNING 阻抗目标路径推进状态。首样本直接初始化。会话变化、模式变化、STOP/FAULT、无效样本、序列丢帧或超过 H1 周期加延迟预算的间隔均打断连续性。时间戳差按无符号回绕计算，沿用原新鲜度和顺序检查。新增 Runtime 用例通过正式 ARM/START、跨回绕的 90 µs 源间隔、丢帧、非法估速、重新启动、STOP 和模式切换，逐个检查目标实际生效及无额外 UPDATE。
- Host Servo 示例和 Host 标定产品入口通过正式初始化启用 48 Hz。示例 `--inspect` 与标定预览/应用/重载提供读回。FCAL v1 指纹仍标识原标定载荷，截止频率属于本地 Runtime 初始参数。旧 36 Hz FCAL 仍保持原增益并可审核重载。UART V1、存储 Schema 和板端默认策略保持原样。链接 C 静态库的调用方须与更新后的公开结构体一起重编。

## 4. 转矩边界和卸载恢复

历史 Plant 的 Kt 为 0.15 N·m/A，Runtime 配置为 0.150000006。Motion 与 Core 的 q/电流上限均为 0.25 A，配置的 0.315 N·m 转矩上限未主导。静止约能维持 **0.0375 N·m**。0.039 N·m 静止保持需 **0.260 A**。纳入该虚拟电机凸极项的保守上界也仅 0.03755625 N·m。采用 Generic 审核值 0.15003572 作敏感性分析，0.25 A 也仅约 0.037509 N·m。历史原试验使用声明的虚拟 Kt。

正向历史用例最后 100 ms 的电磁转矩实测 0.037506 → 0.037501 N·m，转轴速度 −0.304 → −0.306 rad/s，粘性阻尼帮助承受约 0.00182–0.00184 N·m 并伴随持续位移。负载段反电动势峰值低于 0.048 V，实际接受的电压峰值约 0.122 V，远低于 2.4 V，零电压限幅。故限制因素为 q 电流和对应转矩，诊断为 `LOAD_INFEASIBLE_WITH_CURRENT_LIMITS`。

延长近边界载荷至 4.2 s 后达到 0.0566–0.0567 rad 的静态柔顺偏移，与预测平衡点 0.05671 rad 一致。该点未满足 250 ms，两个 A/B 都失败。超载请求始终在 0.25 A 内，真实模型 q 有不足 1 mA 的采样纹波。原及镜像卸载后恢复，均无异常重使能或拒绝事务。独立超载中 STOP 和注入 `INVALID_STATE` 均由下一 H0 确认 INHIBIT，后续零 UPDATE，禁用期间不继续积分。
