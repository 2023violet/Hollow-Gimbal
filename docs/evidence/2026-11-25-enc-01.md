# ENC-01｜编码器线性化（CAL-9）

2026-11-25，分支 `codex/falconfoc-v2-vm01a`，基线 `b897add`（COG-01）。只做软件验证，没有上板。

## 结论

MCU 上的编码器线性化（CAL-9，掩码 32）已接入 Board1：开环旋转磁场正反扫转一圈，保留每圈 1–16 次中非极对数倍数的谐波，生成 128 节点修正表，由现有的 `foc_encoder_init_with_lut` 在方向变换之前施加。SIL `encoder-lut` 场景全部通过：相对被控对象真实角度的位置误差下降 97.6%。

| 默认 | 106,976 B | 109,916 B | +2,940 B |

分桶缓冲复用 CAL-8，RAM 只增加修正表（280 B）。带存储镜像离 122 KB 上限还剩约 9.2 KB。ROM 增量：拟合 1.1 KB，校准管理器 CAL-9 状态约 0.9 KB，整页存储 0.3 KB，串口 0x56 约 0.2 KB，其余为恢复与参数表。报告：[默认](2026-11-25-enc-01/fwsight-default.txt)、[带参数存储](2026-11-25-enc-01/fwsight-persist.txt)。

## 改动

- **Board1**：`foc_board_encoder_lut`（谐波拟合、表与描述符）；编码器初始化时按表的启用状态选择 `foc_encoder_init_with_lut`；校准管理器 CAL-9（状态 23–28、失败码 19、结果位 64），空闲时按 ID 157 重新初始化；齿槽页第二块存表（"FBE1"），整页一起写，CONFIG_ERASE 清表。
- **协议/参数**：ENCODER_LUT_READ 0x56；参数 157–161；CALIBRATE_START 允许 32。
- **CLI/SIL**：`request calibrate --cal-stages encoder`、`encoder-lut-read`、SIL `--encoder-error-rad`、场景 `encoder-lut`、SIL 测试 `test_encoder_linearization`。
- 与方案的差异：滑动平均改为直接取谐波（同样去掉极对数倍数的成分，但不衰减编码器的 2、3 次谐波）。

## 验证

- `test-foc-board-encoder-lut`：合成编码器（1/2/3 次谐波 0.01/0.004/0.002 rad、摩擦滞后 0.003 rad、84 周期齿槽滞后 0.002 rad、噪声 0.5 mrad）节点误差 < 3 计数，一致性 > 0.9；纯噪声 INCONSISTENT 且旧表保留、过陡 RANGE、1 对极 FAILED、线性编码器 NEGLIGIBLE 并清表。
- 固件：齿槽与编码器两块同页往返、只存齿槽时无编码器块、方向不符与 CRC 损坏被拒、极对数不参与；恢复时表按 ID 157 生效（默认开、记录中为 0 时关）。
- SIL `encoder-lut`（[结果](2026-11-25-enc-01/sil-encoder.json)）：注入 0.01 rad 1 次 + 0.004 rad 2 次误差，被控对象 84 周期 0.004 N·m 齿槽 → CAL-9 DONE / VALID，节点最大误差 6.9 计数（注入峰值 146 计数，4.7%），一致性 0.991，峰值 0.0140 rad → 2 rad/s 一圈内位置误差 RMS 0.00759 → 0.00018 rad（−97.6%）→ ID 157 写 0 / 1 后编码器即时切换 → PARAM_SAVE、断电重启后表逐节点相同且生效。
- UART 线上录制：新 ID 之外 3,335 条中 3,332 条与 COG-01 相同；3 条为 ID 136 的 1e-14 量级 θ（新增 ID 的读写使 lockstep 时间推后，I²t 衰减随之变化）。
- 固件 Host 20 项（含 SIL 29 项）、clang 矩阵 11 个工程、质量门禁通过。fwinteg `run1` VERDICT PASS，0 findings，三套工具链各 133 项全过；SDK 技术门禁 PASS。

## 局限

- 每圈 1 次的负载力矩（重心不平衡）造成的滞后与编码器误差无法区分，需空载或配平后标定。
- 对齐电流固定 0.5 A；齿槽或摩擦较大的电机滞后更大，需台架确认。
- 2 对极电机的偶次谐波、1 对极电机的全部谐波无法辨识；需约 2.3 圈自由转动。
- 建议顺序 CAL-9 → CAL-8；已存的齿槽表是用未修正角度测的，需要重测。
