# MIT-01｜MIT 模式与 UART 阻抗设定值

2026-11-24/25，分支 `codex/falconfoc-v2-vm01a`，基线 `55a8be3`（PARAM-01）。只做软件验证，没有上板。

## 结论

CAN 增加 MIT 协议（ID 128 切换），UART 增加 SETPOINT 模式 3；两者都走 Runtime 已有的 IMPEDANCE 阻抗律。Runtime 改为 Kt 跟随实时电机档案，IMPEDANCE 启用后仍可调参和标定。SIL `mit` 场景全部通过。

| 默认 | 97,312 B | 99,900 B | +2,588 B |
| 带参数存储 | 101,112 B | 104,060 B | +2,948 B |

RAM +48 B（CAN 状态与参数）。带参数存储镜像离 124 KB 上限还剩约 22.4 KB。报告：[默认](2026-11-25-mit-01/fwsight-default.txt)、[带参数存储](2026-11-25-mit-01/fwsight-persist.txt)。

## 改动

- **Runtime**：`foc_runtime_impedance_config.torque_constant_from_profile`（放在结构体末尾，保持旧的按位置初始化含义）。Kt = 1.5 × 极对数 × 磁链，初始化和每次调参生效时重算；Kt 为 0 时 IMPEDANCE 不可选；只有固定 Kt 的旧配置仍拒绝调参。
- **Board1**：打开 IMPEDANCE（坐标系编号 `FOC_BOARD_MECHANICAL_FRAME`，转子端上限 Kp 500、Kd 50、τ_ff 100，力矩由实时 q 电流上限约束）。
- **UART**：SET_MODE 3；SETPOINT 模式 3（21 字节：位置、速度、Kp、Kd、τ_ff，输出端）；能力字节算法模式 7 → 15。换算集中在 `foc_serial_impedance()`。
- **CAN MIT**（`foc_can.c`）：命令帧、FC 进入（SET_MODE → 零力矩保持 → ARM/START）、FD 退出、FE 置零（仅停机）、FB 清故障；每帧回复主机 ID，原版 6 字节（默认）或达妙 8 字节。新参数 121、128–134 写进 `parameters.json`，自动进入 TLV 存储。
- **CLI**：`setpoint impedance`、`can --can-command mit-*`、`falconfoc_can.MitClient`、SIL 场景 `mit`。

## 验证

- `test-foc-runtime-impedance`：Kt 跟随磁链（0.01 Wb → 0.06，0.02 Wb → 0.12 N·m/A）、IMPEDANCE 下允许调参、无磁链时不可选、固定 Kt 仍拒绝调参。
- `test-foc-can` 新增 MIT：协议切换后 CANSimple 帧与周期帧停止、回复 ID/长度、静止编码 `05 80 00 80 08 00`、达妙错误位、置零、无磁链时进入超时计入拒绝、切回 CANSimple 后心跳恢复。Python `MitCodecTests` 与该字节一致。
- SIL `mit`（[结果](2026-11-25-mit-01/sil-mit.json)）：CANSimple 标定 Kt 0.10494 → SDO 切 MIT → 原版回复 → 置零（−4.5417 → 0.00019 rad）→ 进入 → 位置 0.5 rad 终值 0.5018（峰值 0.729：Kp 0.5、Kd 0.01、J 0.002 时阻尼比 0.16，属预期超调）→ 速度阻尼均值 3.824 rad/s，与 kd·v/(kd+B) = 3.846 吻合（被控对象 B 0.006）→ 前馈 0.004 N·m 回复均值 0.00403 → 停发后回复错误 D（租约）→ FB 清除 → 退出 → 切回 CANSimple 心跳 → UART 模式 3 终值误差 0.0055 rad。
- UART 线上录制：新增 ID 之外的 2,674 条参数读写回应与 PARAM-01 逐字节相同。
- 固件 Host 17 项（含 SIL 26 项）、clang 矩阵 11 个工程、门禁通过。fwinteg：`run1` 的 uart-check 失败——能力字节算法模式 7 → 15 是新差异，`uart_check.py` 尚未列为已解释；补上 `MIT_ALGORITHM_MODES` 后 `run2` VERDICT PASS，0 findings，三套工具链各 128 项全过。SDK 技术门禁 PASS。

## 局限

- Kd 放大速度估计噪声，阻尼误差低通默认关；H1 为 2 kHz，J 很小时 Kd 过大会离散不稳（约 kd·0.5 ms / J < 2），需台架确认。
- 达妙温度字节为 0；灵足 MIT 细节未核实。MIT 速度量化步长 2·V_MAX/4095（默认 0.032 rad/s）。
- 命令租约默认 2.5 ms：MIT 主机需 ≥ 400 Hz 发送或调大 ID 74。
