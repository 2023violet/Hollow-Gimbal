## 静态可达性生产 API

[`foc_impedance_feasibility_evaluate()`](../../core/include/foc_impedance_feasibility.h) 是无状态 Core 冷路径诊断。复用 IMPEDANCE 的 K、D、Kt 和转矩上限，另收实际允许 Iq、带符号静态载荷、前馈、允许位置误差及来源/适用标志。本轮力矩模型限定 Id≈0。对固定目标，采集方确认 Kt 和外载来源、静摩擦等支撑转矩已计入净载荷或已排除、实际电流能跟踪该预算。来源身份为零或缺少这些条件时给出 UNKNOWN，移动目标给出独立不适用判定。无效数值及不可表示的参数运算统一清空输出并返回 Core 错误。诊断本身没有输出权限。

- 静止时 D 项为零。对电机轴相同正方向，需求转矩等于已确认的净外载，容量为 `min(torque_limit, Kt * Iq_limit)`，余量为容量减外载绝对值。容量、裕度与准入比较采用 Double。独立复核发现 Float32 对容量向上舍入可误判零裕量；已加入 `Kt=.112f, Iq=1.3f` 反例回归，保留真实负裕量。
- 当 K>0 且负载在容量以内，平衡误差为 `(load − feedforward) / K`。按未舍入的误差进行容差判定，再发布 Float32。容量边界允许一段饱和的平衡位置，返回其中离目标最近的误差、零余量和位置未约束标记。K=0 时，只有限幅后前馈平衡净外载才存在静态平衡，此时位置由模型自由。零容量且零载荷也是退化平衡。
- **结果回答理想平衡是否存在、是否进入容差。** 真实闭环收敛、动态稳定性与安全验收依赖额外证据。即便某处存在理想平衡，电流饱和也会消除把系统拉回指定位置的余量。

## 阻尼噪声拆分及独立 Holdout

A 使用原始 K/D，B 只将 D 乘 0.75，C 保持原 K/D，对阻尼反馈速度使用 Float32 一阶后向 Euler。系数为 `a = (2πfc dt)/(1+2πfc dt)`，状态更新为 `v_f += a*(v_sensor−v_f)`。先训练 12/24/48 Hz，按冻结规则选满足静止和动态门槛且固有时间常数 ≤8 ms 的最高 cutoff，得到 48 Hz（3.316 ms）。独立 Holdout 用新的种子、爬行/加减速/反转/负荷轨迹及 464/536 μs 交替源采样间隔，全程使用原 Encoder 量化、同一 LUT 配置和 80 Hz Sensor LPF。闭环 A/B/C 具有同一条件和扰动序列，测得的原码随各自 Plant 运动变化。使用 A 的固定原码记录、LPF 与弹簧样本另行做同采集记录回放，核对阻尼支路对电流请求的作用。

C 的 Host 接缝使用原有前馈入口注入 `D*(v_sensor−v_f)`，夹具逐拍将生产 H1 q 与直接替换阻尼反馈的重算对照。H0 保持原始 Sensor 相位和机械速度推导的电角速度。状态由 Host 持有，使用实际 source timestamp 与已确认端点的间隔；仅在当前 Session 的前一 H0 目标确认后推进已提交滤波历史。当前无效帧不形成 Trial，后续 STOP/FAULT 或 Session 改变清除历史。未引入生产滤波、命令或配置。

所有静止、运动尾段和限流后尾段采用最后 300 ms，2 kHz H1 栅格，对各通道分别求 `x−LPF(x)` 的 RMS，LPF 系数 0.20，保留 01C 的 **35 mA** 绝对门槛，静止 C 还需 ≤0.80×A 且 ≤0.90×B。冻结运动门槛包括爬行 ≤0.030 rad/s、加速/减速/反向速度误差各 ≤0.25 rad/s 和对 A 的相对容差，超调 ≤0.075 rad，卸载恢复 ≤650 ms，另有对 A 的相对门槛。减速、反转和卸载分别计分。各次种子、具体区间和所有数值门槛见冻结清单。

## ARM 静态资源

Arm GNU 14.3.1，Cortex-M4 soft-float，`-Os`。诊断对象 text **936 B**、data/bss **0 B**，函数本地静态栈 **104 B**，调用方输入 **28 B**、结果 **32 B**。诊断使用 Double 乘除、比较与转换，引用 `fmin/fmax` 和 `__aeabi_d*`。隔离滤波算子状态 **8 B**，试探与已确认状态各占一个实例，另需 Host 侧源时刻与身份。独立 ARM wrapper 指令符号 **232 B**，静态栈 **32 B**，使用 Float32 乘加减、一次除法和整数转换的 soft-float helper。栈是编译器局部帧，库调用及抢占仍须独立测量。
